# PM 역할 가이드

> [!NOTE] 문서 목적
> 포트폴리오 문서에서 PM(Project Manager) 역할을 명확히 구분하고, 각 역할별 책임과 성과를 정의합니다.

---

## PM 역할 구분

포트폴리오에서 PM 역할은 **총 사업관리 PM**과 **개발 PM**으로 구분됩니다.

---

## 총 사업관리 PM (Program Manager)

### 역할 정의

**책임 범위**: 전체 프로젝트 관리 (일정, 예산, 고객 관리, 리스크 관리 등)

**주요 업무**:
- 프로젝트 전체 일정 관리 및 마일스톤 달성
- 예산 계획 및 비용 관리
- 고객사와의 커뮤니케이션 및 요구사항 조율
- 프로젝트 리스크 관리 및 대응
- 팀 간 협업 조율
- 최종 납품 및 인수인계 관리

### 담당 프로젝트

**총 사업관리 PM으로 담당한 프로젝트** (5건):

1. **AMS (Analysis Management System)**
   - 프로젝트 ID: `project.ams`
   - 기간: 2024.07~2025.12
   - 발주처: 한국산업기술진흥원
   - 역할: 총괄 PM, AI 종합 플랫폼 개발 총괄
   - 성과: GS 1등급 취득, 특허 출원 2건

2. **CoCTK (Consulting Tool Kit)**
   - 프로젝트 ID: `project.coctk`
   - 기간: 2022.03~2024
   - 발주처: 중소기업기술정보진흥원
   - 역할: 총괄 PM, 엔진 총괄 설계 & 화면설계 개발 총괄
   - 성과: GS 1등급 취득

3. **세아특수강 포미아 DX 실증센터**
   - 프로젝트 ID: `project.pomia_dx_center`
   - 기간: 2025.06~2025.10
   - 발주처: POMIA (재단법인 포항소재산업진흥원)
   - 역할: PM 총괄 (제안서~완료까지 전체 진행)
   - 성과: 제안서 작성, 계획서 작성, 외주 관리, 완료서 작성

4. **테크웰 데이터바우처**
   - 프로젝트 ID: `project.voucher.techwell`
   - 기간: 2024~2025
   - 역할: 총괄 PM
   - 성과: 데이터바우처 프로젝트 완료

5. **뿌리기업 제조데이터 활용 컨설팅 (로드원)**
   - 프로젝트 ID: `project.roadone_consulting`
   - 기간: 2024~2025
   - 고객: 로드원
   - 역할: 프로젝트 총괄(PM), 컨설팅 리딩, 시스템 개발까지 완료
   - 성과: 컨설팅 문서 완료, 시스템 개발 완료

### 성과 지표

## 개발 PM (Development Project Manager)

### 역할 정의

**책임 범위**: 기술 개발 및 구현 관리

**주요 업무**:
- 기술 스택 선정 및 아키텍처 설계
- 개발 일정 관리 및 작업 분배
- 코드 리뷰 및 품질 관리
- 개발 팀 리딩 및 기술적 의사결정
- 기술 문서 작성 및 관리
- 개발 프로세스 개선

### 담당 프로젝트

**개발 PM으로 담당한 프로젝트**: 나머지 모든 프로젝트

**주요 프로젝트 예시**:
- AMS (Analysis Management System) 개발
- CoCTK (Consulting Tool Kit) 개발
- 스마트센서 3종 개발
- 에너지 최적화 시스템 개발
- 기타 13개 솔루션 개발

### 성과 지표

| 지표 | 목표 | 실제 | 달성 여부 |
|------|------|------|----------|
| 코드 품질 | A등급 이상 | [실제값] | [✅/❌] |
| 문서화 완성도 | 90% 이상 | [실제값] | [✅/❌] |
| 개발 일정 준수율 | 85% 이상 | [실제값] | [✅/❌] |
| 기술 혁신 | 논문/특허 | 9편 논문, 특허 | ✅ |

## 역할별 책임 비교

| 항목 | 총 사업관리 PM | 개발 PM |
|------|--------------|---------|
| **일정 관리** | 전체 프로젝트 일정 | 개발 일정 |
| **예산 관리** | 전체 예산 | 개발 예산 |
| **고객 관리** | 직접 커뮤니케이션 | 기술적 요구사항 조율 |
| **팀 관리** | 전체 팀 | 개발 팀 |
| **리스크 관리** | 프로젝트 전체 리스크 | 기술적 리스크 |
| **납품 관리** | 최종 납품 책임 | 기술 납품 지원 |

## PM 역할별 성과 요약

### 총 사업관리 PM 성과

- **담당 프로젝트**: 5건 (2022~2025)
- **납품 성공률**: 100%
- **고객사**: 세아특수강, 포미아, 테크웰, 로드원 등
- **주요 성과**: GS 인증 1등급 2개 취득, 특허 출원 2건, 대기업 납품 성공, 고객 만족도 확보

### 개발 PM 성과

- **담당 프로젝트**: 52건+ (나머지 모든 프로젝트)
- **개발 솔루션**: 13개 독립 솔루션
- **기술 성과**: 10편 논문, GS 인증 2개, 특허 출원/등록 5건
- **주요 성과**: 핵심 엔진 100% 자체 개발, 기술 혁신, 53개+ 프로젝트 수행
