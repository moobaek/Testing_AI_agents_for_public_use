# AMS-MES-비전-센서 통합 플랫폼 제안서 요구조건

## 프로젝트 개요
- 프로젝트명: AMS-MES-비전-센서 통합 플랫폼
- 발주처: 민간 기업
- 문서 유형: 제안서
- 목적: AMS 기반 이상 관리 시스템에 MES 연동, 비전 시스템 통합, 센서 설비 수집 기능을 통합한 통합 플랫폼 구축

## 핵심 요구사항

### 1. 기본 플랫폼: AMS (Anomaly Management System)
- 피쉬본 구조 기반 이상 탐지 및 원인 분석
- 베이지안 네트워크를 통한 확률 기반 분석
- FMEA 자동 생성 기능
- 실시간 이상 탐지 및 알림

### 2. MES 연동 (Tapex_POP 기반)
- 피쉬본 구조 통합: Tapex_POP의 피쉬본 구조를 AMS에 통합
- 학습 데이터 생성 구조: MES 데이터를 활용한 학습 데이터 자동 생성
- 생산 작업 관리 데이터 연동
- PLC 통신 데이터 수집 및 분석

### 3. 비전 시스템 통합 (Image_Labeling_Platform 기반)
- 비전 검사 결과를 AMS 라벨로 활용
- HALCON 기반 이미지 처리 파이프라인 연동
- 비전 검사 결과를 이상 탐지 라벨로 자동 변환
- 이미지 처리 결과를 피쉬본 분석에 활용

### 4. 센서 설비 수집 (Tapex_Rot 기반)
- 센서 설비 데이터 수집 시스템 구축
- 실시간 센서 데이터 수집 및 전송
- AMS와의 데이터 연동
- 센서 데이터 기반 이상 탐지

## 기술 요구사항

### 아키텍처 파일
- AMS: AI_agent_test/AMS/docs/obsidian_design_origin/architecture/
- MES: AI_Agent_Test_Document_Results/Tapex_POP/obsidian_design_origin/architecture/
- 비전: AI_Agent_Test_Document_Results/Image_Labeling_Platform/obsidian_design_image_prcessing/architecture/
- 센서: AI_Agent_Test_Document_Results/Tapex_Rot/

### 통합 요구사항
- 4개 시스템의 아키텍처를 통합하여 단일 플랫폼으로 구축
- 데이터 흐름: 센서 → MES → 비전 → AMS
- 실시간 데이터 처리 및 분석
- 통합 대시보드 제공

## 비즈니스 가치
- 제조 공정의 이상 상황을 실시간으로 탐지하고 분석
- MES 데이터와 비전 검사 결과를 통합하여 정확도 향상
- 센서 데이터를 활용한 예측 정비 및 품질 관리
- 통합 플랫폼으로 운영 효율성 향상
