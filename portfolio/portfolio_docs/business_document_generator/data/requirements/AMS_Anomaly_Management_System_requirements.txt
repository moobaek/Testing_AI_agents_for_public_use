# AMS (Anomaly Management System) 사업계획서 요구조건

## 프로젝트 기본 정보

**프로젝트명**: AMS (Anomaly Management System) 개발
**목적**: AI 기반 이상 관리 시스템으로, 제조업 공장에서 발생하는 이상 상황을 자동으로 탐지하고, 원인을 분석하며, 대응 방안을 제시하는 통합 솔루션 개발
**배경**: 제조업 공장에서 발생하는 이상 상황을 수동으로 탐지하고 분석하는 기존 방식의 한계를 극복하기 위해 AI 기반 자동화 시스템이 필요함

## 지원분야 및 기술분류

**지원분야**: AI 기반 품질 관리 시스템
**기술분류**:
- 대분류: 융합서비스
- 중분류: 인공지능
- 소분류: 머신러닝 기반 이상 탐지
- 융합기술: AI 기반 이상 관리 및 FMEA 자동화

## 핵심 요구사항

### 기술적 요구사항
- 머신러닝 기반 실시간 이상 탐지 시스템
- 피쉬본 구조(FBS) 기반 원인 분석 시스템
- 베이지안 네트워크(RMS) 기반 확률 분석 시스템
- FMEA (Failure Mode and Effects Analysis) 자동 생성 시스템
- 그래프 데이터베이스(Neo4j)를 활용한 관계 분석
- 통합 관리 시스템 (MLS, FBS, RMS 통합)

### 기능적 요구사항
- 실시간 이상 탐지 및 알림 기능
- 자동 원인 분석 기능 (피쉬본 구조, 베이지안 네트워크)
- FMEA 문서 자동 생성 기능
- 시각화 대시보드 기능
- 통합 관리 시스템 기능
- Windows Forms 및 웹 기반 사용자 인터페이스

### 비기능적 요구사항
- 실시간 처리 성능 (이상 탐지 지연 최소화)
- 확장 가능한 아키텍처 (다양한 공장 환경 지원)
- 안정성 및 신뢰성 (24/7 운영 가능)
- 사용자 친화적 인터페이스
