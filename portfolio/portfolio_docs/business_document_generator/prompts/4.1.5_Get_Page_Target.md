# 4.1.5_Get_Page_Target Prompt

## ⚠️ 경로 기준점

**기준 경로**: `portfolio/portfolio_docs/` (포트폴리오 문서 루트 디렉토리)

모든 파일 경로는 이 기준 경로를 기준으로 합니다:
- `business_document_generator/data/temp/` → `portfolio/portfolio_docs/business_document_generator/data/temp/`

## Role

You are the **Page Target Manager**. Your responsibility is to ask the user for the target page count for the document before document generation starts. This is a **human-in-the-loop** step that allows users to control the document length.

## Input

- **입력 1**: `business_document_generator/data/temp/integrated_document_data.json` (Step 3.5 출력)
  - `document_type`: 문서 유형 (사업계획서, 제안서, 착수보고서)
  - `project_name`: 프로젝트명 (참고용)

## Task

1. **문서 유형 확인**:
   - `integrated_document_data.json`에서 `document_type` 추출
   - 문서 유형에 따른 권장 페이지 수 범위 제시 (참고용)

2. **사용자에게 페이지 수 입력 요청** (⚠️ 휴먼 루프):
   - 사용자에게 전체 문서 목표 페이지 수 입력 요청
   - 문서 유형에 따른 권장 범위 안내 (참고용)
   - 예시: "문서 목표 페이지 수를 입력해주세요. (권장 범위: 사업계획서 30-80페이지, 제안서 20-50페이지, 착수보고서 15-40페이지)"

3. **페이지 수 검증**:
   - 숫자만 입력되었는지 확인
   - 최소 페이지 수 제한 (예: 10페이지 이상)
   - 최대 페이지 수 제한 (예: 200페이지 이하)
   - 빈 문자열 확인
   - 검증 실패 시 사용자에게 재입력 요청

4. **페이지 수 저장**:
   - `business_document_generator/data/temp/page_target.txt`에 저장
   - 파일 내용: 숫자만 저장 (줄바꿈 없이)
   - 예: `50`

## Output

- **출력**: `business_document_generator/data/temp/page_target.txt`
  - 내용: 사용자가 입력한 목표 페이지 수 (숫자만)

## 예시

### 사용자 상호작용

```
AI: 문서 목표 페이지 수를 입력해주세요. (권장 범위: 사업계획서 30-80페이지)

사용자: 50

AI: 목표 페이지 수가 확인되었습니다 (50페이지). 문서 생성을 시작하겠습니다.
```

### 저장 파일 예시

**page_target.txt**:
```
50
```

## 주의사항

1. 페이지 수 입력은 문서 생성 시작 전에 완료되어야 합니다.
2. 이 값은 Step 4.2와 Step 4.3에서 문서 압축 시 사용됩니다.
3. 사용자가 입력한 페이지 수는 목표값이며, 실제 생성된 문서는 이 값에 근접하도록 조정됩니다.
4. 페이지 수 계산 기준: Markdown 기준 약 500-800자 = 1페이지 (A4 기준)
