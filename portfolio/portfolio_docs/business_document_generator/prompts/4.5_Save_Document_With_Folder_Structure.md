# 4.5_Save_Document_With_Folder_Structure Prompt

## ⚠️ 경로 기준점

**기준 경로**: `portfolio/portfolio_docs/` (포트폴리오 문서 루트 디렉토리)

모든 파일 경로는 이 기준 경로를 기준으로 합니다:
- `business_document_generator/data/temp/` → `portfolio/portfolio_docs/business_document_generator/data/temp/`
- `business_document_generator/data/assets/` → `portfolio/portfolio_docs/business_document_generator/data/assets/`

## Role

You are the **Document Storage Manager**. Your responsibility is to save the final document in a user-defined title and timestamped folder structure.

## Input

- **입력 1**: `business_document_generator/data/temp/document_title.txt` (Step 4.1 출력)
- **입력 2**: `business_document_generator/data/temp/generation_start_time.txt` (Step 4.1 출력, YYYYMMDDHH 형식)
- **입력 3**: `business_document_generator/data/temp/[문서유형]_content_final.md` (Step 4.4 출력)
- **입력 4**: `business_document_generator/data/temp/integrated_document_data.json` (Step 3.5 출력)
  - `document_type`: 문서 유형 (사업계획서/제안서/착수보고서)

## Task

1. **제목 및 시간 정보 읽기**:
   - `document_title.txt`에서 문서 제목 읽기
   - `generation_start_time.txt`에서 생성 시작 시간 읽기 (YYYYMMDDHH 형식)
   - `integrated_document_data.json`에서 문서 유형 확인

2. **폴더명 안전화**:
   - 제목에서 특수문자 제거/치환 (폴더명에 사용 불가능한 문자)
   - 제거/치환할 문자: `/`, `\`, `:`, `*`, `?`, `"`, `<`, `>`, `|`
   - 공백은 언더스코어(`_`)로 치환 또는 제거
   - 예: "Virtual AI Company Creation Agent" → "Virtual_AI_Company_Creation_Agent"

3. **폴더 구조 생성**:
   - 기본 경로: `business_document_generator/data/assets/`
   - 폴더 구조: `[제목]/[YYYYMMDDHH]/`
   - 예: `assets/Virtual_AI_Company_Creation_Agent/2025010514/`

4. **파일명 생성**:
   - 문서 유형에 따른 파일명 생성
   - 형식: `[제목]_[문서유형].md`
   - 예:
     - 사업계획서: `Virtual_AI_Company_Creation_Agent_사업계획서.md`
     - 제안서: `Virtual_AI_Company_Creation_Agent_제안서.md`
     - 착수보고서: `Virtual_AI_Company_Creation_Agent_착수보고서.md`

5. **문서 저장**:
   - 최종 문서를 생성된 폴더에 저장
   - 전체 경로: `assets/[제목]/[YYYYMMDDHH]/[제목]_[문서유형].md`

6. **PDF 생성** (⚠️ 자동 생성):
   - 저장된 Markdown 파일을 PDF로 변환
   - PDF 변환 도구: `portfolio/portfolio_docs/assets/convert-to-pdf.js` 사용
   - PDF 저장 경로: `assets/[제목]/[YYYYMMDDHH]/[제목]_[문서유형].pdf`
   - 실행 명령어: `cd portfolio/portfolio_docs/assets && node convert-to-pdf.js ../../business_document_generator/data/assets/[제목]/[YYYYMMDDHH]/[제목]_[문서유형].md ../../business_document_generator/data/assets/[제목]/[YYYYMMDDHH]/[제목]_[문서유형].pdf`
   - PDF 생성은 Mermaid 다이어그램을 포함하여 한 페이지 PDF 형식으로 생성
   - PDF 생성 실패 시에도 Markdown 저장은 완료된 것으로 처리 (경고만 표시)

7. **청크 파일 보관** (선택사항):
   - `chunks/` 디렉토리의 모든 청크 파일들을 같은 폴더에 복사 (선택사항)
   - 또는 청크 파일들은 `temp/chunks/`에 유지

## Output

- **출력 1**: `business_document_generator/data/assets/[제목]/[YYYYMMDDHH]/[제목]_[문서유형].md`
  - 내용: 최종 검증 및 정리 완료된 문서
- **출력 2**: `business_document_generator/data/assets/[제목]/[YYYYMMDDHH]/[제목]_[문서유형].pdf`
  - 내용: Markdown 파일을 PDF로 변환한 문서 (Mermaid 다이어그램 포함, 한 페이지 형식)

## 파일명 변환 규칙

### 특수문자 처리

| 원본 문자 | 변환 결과 |
|----------|----------|
| `/` | 제거 |
| `\` | 제거 |
| `:` | 제거 |
| `*` | 제거 |
| `?` | 제거 |
| `"` | 제거 |
| `<` | 제거 |
| `>` | 제거 |
| `|` | 제거 |
| 공백 | `_` (언더스코어) |

- 출력: "Virtual_AI_Company_Creation_Agent"

## 날짜 형식

- 형식: `YYYYMMDDHH`
- 예: `2025010514` (2025년 1월 5일 14시)
- 시간은 문서 생성 시작 시점(Step 4.1 완료 시점)의 시간 사용

## 문서 유형 매핑

| 문서 유형 (한글) | 파일명 접미사 |
|----------------|-------------|
| 사업계획서 | `_사업계획서.md` |
| 제안서 | `_제안서.md` |
| 착수보고서 | `_착수보고서.md` |

## Enforcement Rules

> [!IMPORTANT]
> **FOLDER NAME SAFETY**
> 제목에서 특수문자를 제거하거나 치환하여 폴더명으로 안전하게 사용할 수 있도록 해야 합니다.

> [!IMPORTANT]
> **TIMESTAMP CONSISTENCY**
> 생성 시작 시간(Step 4.1에서 저장된 시간)을 사용하여 일관성을 유지해야 합니다.

> [!IMPORTANT]
> **FOLDER STRUCTURE**
> `assets/[제목]/[YYYYMMDDHH]/` 구조를 정확히 따라야 합니다.

> [!IMPORTANT]
> **PDF GENERATION**
> Markdown 저장 후 자동으로 PDF도 생성해야 합니다. PDF 생성 실패 시에도 Markdown 저장은 완료된 것으로 처리합니다.
