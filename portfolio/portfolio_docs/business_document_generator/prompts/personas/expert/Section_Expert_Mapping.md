## 사용 방법

1. 문서 유형 확인 (사업계획서/제안서/착수보고서)
2. 섹션 번호 확인
3. 해당하는 전문가 페르소나 파일 로드
4. 전문가 페르소나 + 발주처 유형 페르소나 + 순룡 기본 스타일 통합 적용

## 페르소나 통합 순서

1. **전문가 페르소나** 로드 (섹션별)
2. **발주처 유형 페르소나** 로드 (정부/민간/공공/기타)
3. **순룡 기본 스타일** 로드
4. 세 가지 페르소나를 통합하여 섹션 작성
