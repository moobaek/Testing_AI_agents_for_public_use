# 권순룡 자기소개서 - EY한영 Gen AI 서비스 및 애플리케이션 개발 컨설턴트

---

## 자기소개서

EY AI팀이 추구하는 "기획-개발-실행-고도화까지 한 팀 내에서 유기적으로 연결된 구조"는 5년간 제조 AI 프로젝트를 총괄 PM으로 이끌며 체득한 방식과 정확히 일치합니다. 47개 프로젝트를 성공적으로 완수하며 PoC부터 배포까지 전 과정을 설계하고 실행한 경험을 바탕으로, EY AI팀에서 고객사와 함께 실전형 AI 서비스를 만들어가고 싶습니다.

**Gen AI 서비스 개발 역량**

FMEA 자동화 생성 시스템에서 Claude Sub-Agent 기반 Multi-Agent Workflow를 설계하고 구현한 경험이 있습니다. 8개 독립 Sub-Agent(R&D 3개, Manufacturing 3개, QA 2개)가 협업하는 구조를 구축했으며, Master Orchestrator가 전체 워크플로우를 조율합니다. 코딩 에이전트의 역설계 시스템 구조를 적용하여, 복잡한 FMEA 프로세스를 Phase 0-5 자동화 워크플로우로 분해했습니다. 이 경험은 EY AI팀의 "LLM/ML 기반 기술을 활용한 실전형 AI 시스템 개발 및 적용" 업무에 직접 기여할 수 있습니다.

프롬프트 평가 엔진에서는 AI Gatekeeper 역할로 모든 AI 생성물의 품질을 전수 평가하는 시스템을 개발했습니다. 17가지 역할별 동적 가중치 시스템과 MLOps Priority Matrix(Structural 40%, Correctness 30%, Relevancy 20%, Tone 10%)를 적용하여 Quality, Consistency, Cost 3차원 평가를 수행합니다. 병렬 처리 구조로 4개 메트릭을 동시에 평가하여 효율성을 극대화했습니다.

**NLP 및 챗봇 개발 경험**

코아아이티 프로젝트에서 BERT/DistilBERT 기반 자연어 처리 모델을 개발했습니다. 한약재/건강식품 데이터를 분석하고, 효과 및 주의사항 정보를 구조화하여 챗봇 응답 생성 시스템을 설계했습니다. CSV 기반 자연어 처리 파이프라인을 구축하고, 공정 데이터 토큰화 및 벡터화를 수행한 경험은 EY AI팀의 "문서 요약, 자동 분석, 지식 검색, 챗봇 등 AI 응용 서비스 기획/개발" 업무와 직접적으로 연결됩니다.

Factory Ontology Manager AI Agent에서는 React 18.3.1 + TypeScript + Flask 풀스택으로 개발하여, 자연어 기반 공정 문서 파싱 및 캔버스 레이아웃 자동 생성 기능을 구현했습니다. LangGraph 기반 자연어 쿼리와 Instructor(Pydantic 기반 LLM 검증)를 통합하여 레이아웃 생성 시간을 80% 단축했습니다.

**기업 고객 대상 컨설팅 역량**

5년간 47개 프로젝트를 성공적으로 완수했으며, 다양한 산업의 실제 데이터를 기반으로 문제를 정의하고 해결한 경험이 있습니다. 세아특수강, 포미아에 AMS(Analysis Management System)를 정식 납품했고, 테크웰, 신성오토텍 AMS 컨설팅을 수행했습니다. O-WELL Japan과 4년간 글로벌 DX 프로젝트를 진행하며 기획부터 개발, 실행, 고도화까지 전 주기를 경험했습니다.

AMS에서 49개 Python 모듈을 100% 자체 개발하여 GS 인증 1등급 2개(CoCTK, AMS/PDS)를 취득했습니다. 베이지안 네트워크 기반 이상 탐지 모델로 93.7%의 정확도를 달성했으며, 10편의 학술 논문을 발표했습니다. "포기할 건 포기하고 잘하는 것에 집중한다"는 GS 인증 전략처럼, 관리자가 요구하는 필수 조건에 자원을 집중하는 실용주의적 접근으로 프로젝트를 성공시켜왔습니다.

EY AI팀에서 비즈니스 컨설턴트, 기획자, 엔지니어들과 협업하며 다양한 산업 고객의 비즈니스 문제를 AI로 해결하고, 이를 제품이나 서비스로 구현하는 실전 프로젝트에 기여하고 싶습니다. "모델보다 데이터, 데이터보다 정보, 지식구조를 정리하는 현장친화적 연구원"이라는 철학을 바탕으로, 화려함보다 현장에서 실제로 작동하는 AI 서비스를 만들어가겠습니다.
