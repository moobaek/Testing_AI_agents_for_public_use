## 지원동기

저는 5년 동안 제조/에너지 현장에서 “AI 백엔드/엔진 개발 → 연구·과제 관리(완료보고/산출물) → 플랫폼 총괄 PM → LLM/Agent”로 역할을 확장해 왔습니다. 초기 3년은 가상센서/전력예측/품질예측 등 **AI 엔진을 실제 서비스 형태로 만들기 위한 백엔드와 데이터 파이프라인**을 중심으로 수행했고, 동시에 과제 수행 과정의 산출물/완료보고를 책임지며 현장·정부·협력사 커뮤니케이션을 병행했습니다. 이후 CoCTK/AMS에서 플랫폼 관점의 품질/검증/납품까지 리드하며, 최근에는 Multi-Agent, RAG, MCP, LangGraph 기반으로 업무 자동화까지 직접 설계·구현했습니다.

디비아이엔씨 AX(AI Transformation) 팀의 "AX(AI Transformation) 과제 수행을 위한 LLM 기반 AI 서비스 및 플랫폼 설계와 구축", "AI Agent 설계 및 개발 (업무 자동화, 지식 탐색, 의사결정 지원 등)", "RAG 기반 정보 검색·추출 시스템 구축 및 성능 고도화" 업무는 제가 수행한 프로젝트들과 직접적으로 연결됩니다. 특히 Neo4j 그래프 DB를 활용한 지식 그래프 RAG 시스템 구축 경험, Multi-Agent 오케스트레이션 경험, MCP 프로토콜 기반 시스템 구축 경험이 디비아이엔씨의 AI Transformation 과제에 기여할 수 있습니다.

디비아이엔씨의 대기업 규모의 안정적인 조직과 전산조직 자문 및 시스템 통합 전문성을 바탕으로, 제가 쌓아온 AI Agent 시스템 개발 경험과 LLM 기반 플랫폼 구축 전문성을 통해 AX(AI Transformation) 과제의 성공적 수행에 기여하고 싶습니다. 특히 제조업 도메인에서 29개 스마트공장 프로젝트를 수행하며 쌓은 도메인 전문성과 GS 인증 1등급 2개, 정식 납품 2곳 등 검증된 성과를 바탕으로 디비아이엔씨의 AI Transformation 여정에 함께하고 싶습니다.

## 경력기술(경력목표 포함)

5년간 한솔코에버 연구소에서 다양한 제조/에너지 프로젝트를 수행했습니다. 초기(2020~2023)는 **AI 백엔드 엔진 개발 + 연구/과제 운영**이 중심이었습니다. 현장 데이터의 품질/정합성 이슈(결측, 편향, 센서 불안정)를 전제로, 가상센서/전력·품질 예측/공정 불량 예측 등 시계열 기반 AI 엔진을 개발·고도화하고, 결과를 논문/보고서/완료 산출물로 정리해 이해관계자(현장/정부/협력사)가 납득할 수 있는 형태로 전달해 왔습니다.

이후(2022~2025)에는 CoCTK/AMS에서 엔진을 플랫폼으로 확장하며 총괄/기술 PM 역할을 수행했고, GS 인증 및 납품 단계까지 리드했습니다. 최근(2025~)에는 Multi-Agent 기반 자동화(FMEA 자동화, 프롬프트 평가 엔진, MCP 기반 PM Agent, LangGraph 워크플로우 오케스트레이션)를 구축해 “사람이 하던 문서/의사결정 흐름”을 시스템으로 전환하는 방향에 집중하고 있습니다.

AMS 프로젝트에서는 Neo4j 그래프 DB를 활용한 지식 그래프 RAG 시스템을 구축하여 공정 관리 문서 기반 FMEA 자동 생성 기술을 검증했으며, GS 인증 1등급을 취득하고 세아특수강과 포미아에 정식 납품했습니다. Factory Ontology Manager AI Agent에서는 자연어 기반 공정 문서 파싱 시스템을 구축하여 레이아웃 생성 시간을 80% 단축하는 성과를 달성했습니다. 프롬프트 평가 엔진에서는 AI Gatekeeper 시스템을 구축하여 25개+ 프롬프트를 전수 평가하는 완전 자동화 시스템을 구현했습니다.

**단기 목표 (1-2년)**: 디비아이엔씨 AX(AI Transformation) 팀에서 AI Agent 시스템 설계 및 개발 전문성을 더욱 심화하고, Multi-Agent 오케스트레이션과 RAG 기반 정보 검색 시스템 구축 경험을 확장하여 팀의 핵심 역량으로 성장하고 싶습니다. 특히 LangGraph, LangSmith 등 최신 Agent 프레임워크를 활용한 실무 경험을 쌓고, Document AI를 활용한 문서 데이터 추출·가공 파이프라인 설계 및 개발 전문성을 강화하겠습니다.

**장기 목표 (3-5년)**: AI Agent 시스템 아키텍처 설계 전문가로 성장하여 디비아이엔씨의 AI Transformation 전략 수립에 기여하고, 다양한 도메인(보험, 금융, 제조 등)에서 AI Agent 시스템을 설계·구축하는 리드 엔지니어로 성장하고 싶습니다. 또한 학술 연구 활동을 지속하여 AI Agent 시스템 관련 논문을 발표하고, 업계 전문가로 인정받는 것이 목표입니다.

## 입사 후 기여방안

디비아이엔씨 AX(AI Transformation) 팀에 입사하여 제가 보유한 AI Agent 시스템 개발 경험과 LLM 기반 플랫폼 구축 전문성을 바탕으로 다음과 같이 기여하고 싶습니다.

**AI Agent 설계 및 개발 기여**: FMEA 자동화 생성 시스템에서 8개 독립 Sub-Agent 협업 시스템을 설계한 경험을 바탕으로, 디비아이엔씨의 업무 자동화, 지식 탐색, 의사결정 지원을 위한 AI Agent 시스템을 설계하고 개발하겠습니다. 특히 Master Orchestrator 설계 경험과 Phase 0~5 자동화 워크플로우 구축 경험을 활용하여 복잡한 업무 프로세스를 구조화하고 자동화하는 시스템을 구축하겠습니다.

**RAG 기반 정보 검색 시스템 구축**: AMS 프로젝트에서 Neo4j 그래프 DB를 활용한 지식 그래프 RAG 시스템을 구축한 경험을 바탕으로, 디비아이엔씨의 다양한 문서와 데이터를 활용한 RAG 기반 정보 검색·추출 시스템을 구축하고 성능을 고도화하겠습니다. 특히 오픈소스 임베딩 모델 및 벡터 DB 기반 검색 시스템 구축 경험을 활용하여 최신 기술을 적용한 시스템을 설계하겠습니다.

**LangGraph/CrewAI 워크플로우 오케스트레이션**: Original_Development_Plan에서 LangGraph/CrewAI 방식 워크플로우 오케스트레이션을 구현한 경험을 바탕으로, 디비아이엔씨의 AI 서비스 개발 프로세스를 자동화하고 효율화하는 워크플로우 시스템을 구축하겠습니다. 특히 상태 기반 진행 모니터링 및 완료 조건 판단 시스템을 활용하여 개발 프로세스의 투명성과 효율성을 높이겠습니다.

**Document AI 활용 문서 파이프라인 구축**: Factory Ontology Manager AI Agent에서 자연어 기반 공정 문서 파싱 시스템을 구축한 경험과 PM Agent에서 HWP 파서를 통한 문서 처리 경험을 바탕으로, 디비아이엔씨의 다양한 문서를 자동으로 파싱하고 구조화하는 Document AI 파이프라인을 설계하고 개발하겠습니다. 특히 오픈소스 기반 Document AI를 활용한 OCR 및 문서 데이터 추출·가공 파이프라인을 구축하여 업무 효율성을 높이겠습니다.

**LLM 기반 MLOps 환경 구축**: 프롬프트 평가 엔진에서 AI Gatekeeper 시스템을 구축하고 MLOps Priority Matrix 기반 가중치 시스템을 구현한 경험을 바탕으로, 디비아이엔씨의 LLM 기반 서비스 모델 서빙, 운영 자동화 및 성능 개선을 위한 MLOps 환경을 구축하겠습니다. 특히 17가지 역할별 동적 가중치 시스템과 병렬 처리 구조를 활용하여 효율적인 MLOps 시스템을 설계하겠습니다.

**협업 및 지식 공유**: 5년간 다양한 프로젝트를 수행하며 쌓은 협업 경험과 PM 경험을 바탕으로, 팀 내 지식 공유와 협업 문화를 조성하고, 최신 AI 트렌드를 팀에 전파하여 디비아이엔씨의 AI Transformation 역량을 강화하겠습니다.
