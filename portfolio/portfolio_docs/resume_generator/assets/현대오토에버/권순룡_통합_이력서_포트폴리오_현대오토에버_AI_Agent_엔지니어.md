## 🎯 지원 동기

현대오토에버 인공지능기술실의 '살아있는 AI' 기술 개발에 기여하고자 지원합니다.

5년 5개월간의 경험을 통해 가장 중요하게 배운 것은 **"AI는 기술이 아니라 비즈니스 문제를 해결하는 도구"** 라는 점입니다. 백엔드 AI 개발자였지만 코딩 에이전트를 만들어 외주 개발자 관리 문제를 해결했고, FMEA 자동화로 공장 관리자가 이해할 수 있는 언어로 복잡한 기술을 변환했으며, Dual-Tier AI 아키텍처로 LLM 비용을 87% 절감했습니다. 이는 단순히 기술을 쌓은 것이 아니라, 실제 현장의 니즈를 파악하고 비용 효율성을 고려한 솔루션 설계 능력입니다.

현대오토에버의 미래 모빌리티 비전은 단일 AI가 아닌 다양한 에이전트들이 협업하는 Multi-Agent 생태계가 필요할 것입니다. 제가 설계한 Master Orchestrator 기반 8개 Sub-Agent 협업 구조와 MCP 기반 채널 연동 아키텍처는 바로 이러한 생태계의 기반이 될 수 있습니다. 특히 지식그래프와 온톨로지를 활용한 DB Grounding 경험은 모빌리티 도메인의 복잡한 관계를 구조화하는 데 직접적으로 활용 가능합니다.

인공지능기술실의 자율성 기반 성장 문화와 멀티모달 기반 궁극적 AI 개발 지향에 깊이 공감합니다. 함께 신기술을 공부하고 구체적 결과가 있는 실질적 기술 응용을 통해 현대오토에버의 AI 생태계를 구축하는 데 기여하고 싶습니다.

## 💪 핵심 역량

### AI Agent 아키텍처 설계 및 Orchestration 구현

Multi-Agent 시스템을 설계하고 워크플로우를 오케스트레이션하는 전문성을 보유하고 있습니다. FMEA 자동화 시스템에서 Master Orchestrator 기반 8개 독립 Sub-Agent 협업 구조를 설계했으며, Claude Sub-Agent 기반으로 R&D, Mfg, QA 등 8개의 독립 Sub-Agent가 협업하는 구조를 설계했습니다. LangGraph/CrewAI를 활용하여 Phase 0-13 워크플로우를 설계하여 개발 프로세스의 각 단계를 자동화했으며, 상태 기반 진행 모니터링 및 완료 조건 판단 시스템을 설계했습니다.

**주요 프로젝트**: FMEA 자동화 Multi-Agent 시스템, 코딩 에이전트, Virtual Company Creation Agent  
**핵심 성과**: 8개 Sub-Agent 협업 구조 설계, Phase 0-13 워크플로우 자동화, Master Orchestrator 설계  
**기술 스택**: LangGraph, CrewAI, Claude Agent, Multi-Agent System

### MCP 기반 채널 연동 아키텍처 설계 및 구현

MCP (Model Context Protocol)를 활용하여 에이전트 간 통신을 구현하고 채널 연동 아키텍처를 설계하는 경험을 보유하고 있습니다. PM Agent에서 32개 Python MCP 서버를 개발하여 비정형 문서(HWP, DOCX, XLSX)를 자동 파싱하는 Docker 기반 파서 서버를 구축했습니다. MCP Protocol을 통해 에이전트 간 통신을 구현하여 유기적 네트워크를 구축했으며, 내·외부 에이전트 연동이 가능한 구조를 설계했습니다.

**주요 프로젝트**: PM Agent, TAM_Hub  
**핵심 성과**: 32개 Python MCP 서버 개발, 비정형 문서 자동 파싱, 에이전트 간 통신 구현  
**기술 스택**: MCP, Python, Docker, HWP 파서

### 지식그래프, 온톨로지 관련 개발 경험

지식그래프와 온톨로지를 활용하여 데이터를 구조화하고 관계를 분석하는 전문성을 보유하고 있습니다. Neo4j 그래프 DB를 활용하여 4M2E 관계 온톨로지를 정의했으며, Factory Ontology Manager AI Agent에서 자연어 기반 공정 문서 파싱 및 DB Grounding, Ontology Mapping을 구현했습니다. Virtual Company Creation Agent에서 14 Layer 좌표 체계 및 온톨로지 구조를 설계하여 복잡한 비즈니스 프로세스를 구조화했습니다.

**주요 프로젝트**: AMS, DPS, Factory Ontology Manager AI Agent, Virtual Company Creation Agent  
**핵심 성과**: Neo4j 4M2E 관계 온톨로지 정의, 자연어 기반 온톨로지 매핑, 14 Layer 좌표 체계 설계  
**기술 스택**: Neo4j, 온톨로지, DB Grounding, Ontology Mapping

### 다양한 Agentic AI 라이브러리, 서비스, 플랫폼에 대한 경험

Claude Agent, LangGraph, CrewAI 등 다양한 Agentic AI 라이브러리와 플랫폼을 활용하여 AI Agent를 개발한 경험을 보유하고 있습니다. Claude Sub-Agent를 활용하여 Multi-Agent 시스템을 개발했으며, LangGraph Chain 설계 방법론과 CrewAI 워크플로우 오케스트레이션을 구현했습니다. LLM 트러블슈팅 Mock 테스트 시스템을 개발하여 AI Agent의 안정성을 확보했습니다.

**주요 프로젝트**: FMEA 자동화 Multi-Agent 시스템, 코딩 에이전트, Virtual Company Creation Agent  
**핵심 성과**: Claude Sub-Agent 기반 Multi-Agent 시스템, LangGraph/CrewAI 오케스트레이션, LLM 트러블슈팅 시스템  
**기술 스택**: Claude Agent, LangGraph, CrewAI, LLM

### AI Agent 도구, 리소스 및 시스템 연계 역량

AI Agent가 외부 시스템과 연계하여 작동하도록 설계하고 구현하는 경험을 보유하고 있습니다. Neo4j 기반 지식 그래프 RAG 시스템을 구축하여 LLM의 지식 기반을 확장했으며, Factory Ontology Manager AI Agent에서 자연어로 기술된 공정 문서를 파싱하고 실제 공장 데이터(DB)와 매핑하여 공장 모니터링 캔버스 레이아웃을 자동 생성했습니다. GFS (Grape File System)를 설계하여 LLM을 서포트하는 특화 중간 DB를 구축했습니다.

**주요 프로젝트**: FMEA 자동화 Multi-Agent 시스템, Factory Ontology Manager AI Agent, Virtual Company Creation Agent  
**핵심 성과**: Neo4j 기반 지식 그래프 RAG 구축, DB Grounding 및 Ontology Mapping, GFS 특화 중간 DB 설계  
**기술 스택**: Neo4j, RAG, GFS, DB Grounding

### MLOps 파이프라인과 서비스 연계 경험

MLOps 파이프라인을 설계하고 서비스와 연계하는 경험을 보유하고 있습니다. AMS 프로젝트에서 데이터 전처리부터 FMEA 생성까지 전체 파이프라인을 자동화했으며, 8단계 시계열 데이터 파이프라인을 설계했습니다. 실시간 스트리밍과 데이터 품질 관리를 구현했으며, Docker 컨테이너 기반 마이크로서비스 아키텍처를 구축했습니다.

**주요 프로젝트**: AMS, FMEA 자동화, DPS  
**핵심 성과**: 8단계 시계열 데이터 파이프라인, 실시간 스트리밍 구현, 데이터 품질 관리 자동화  
**기술 스택**: Python, Docker, Kubernetes, MLOps

**비즈니스 가치**: AI 생성물의 품질을 보장하여 신뢰성 있는 AI 시스템 구축에 기여했습니다. 모든 AI 생성물의 입구를 통제하여 품질 관리를 자동화했습니다.

**현장 친화적 기술 철학 (Field-Friendly Tech)**:
- 화려함보다는 **편리함** 우선
- 고성능 서버보다는 **초저성능에서도 돌아가는** 실용적 설계
- 복잡한 규칙이라도 **규칙 기반으로 정보화**해야 현장이 쓸 수 있음
- 최종 형태는 고전적이어도 **현장 친화적**이어야 함

**고객 커뮤니케이션 3원칙**:
1. **고객과 적대하지 않는다** - 신뢰 기반 협업
2. **정부 문서 외적으로 고객의 진짜 AI 목표를 따로 파악한다** - 화려한 보고서와 실제 니즈는 다르다
3. **기술 용어를 쓰지 않는다** - 현장 관리자가 이해할 수 있는 언어로 소통

AI Agent는 단순한 자동화 도구가 아니라, 복잡한 비즈니스 프로세스를 구조화하고 자동화하는 지능형 시스템입니다. 이러한 철학을 바탕으로 9개 이상의 AI Agent를 개발했으며, Multi-Agent 시스템을 설계하고 워크플로우를 오케스트레이션하는 전문성을 갖추었습니다.
