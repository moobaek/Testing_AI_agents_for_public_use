### 1. LLM/RAG 기반 서비스 설계 경험: Neo4j 지식 그래프 RAG 시스템

2025년, FMEA 자동화 생성 시스템을 설계하면서 Neo4j 그래프 DB를 활용한 지식 그래프 RAG 시스템을 구축했습니다. 공정 관리 문서를 파싱하여 지식 그래프에 저장하고, 상관/확률 네트워크 최적 경로 분석을 통해 FMEA를 자동 생성하는 시스템입니다.

이 시스템의 핵심은 "비개발자가 이해할 수 있는 언어로 변환"하는 것이었습니다. 난해한 FBS(Fishbone Structure), 패턴 분석, 확률 네트워크를 FMEA 형식으로 변환하여 공장 관리자가 이해할 수 있는 언어로 제공했습니다. 그 결과, 공장 관리자 이해도 90% 이상 향상, 기술 설명 시간 70% 이상 절감이라는 성과를 달성했습니다.

위메이드의 "비개발자가 이용할 자연어 데이터 조회 서비스 구축" 요구사항과 정확히 일치하는 경험입니다. 게임 데이터의 복잡한 관계를 지식 그래프로 구조화하고, 자연어 질의를 통해 직관적으로 데이터를 조회할 수 있는 시스템을 설계할 수 있습니다.

또한 Master Orchestrator 기반 8개 독립 Sub-Agent 협업 구조를 설계했습니다. R&D Team 3개, Manufacturing Team 3개, QA Team 2개로 구성된 이 구조는 각 Sub-Agent가 전문 영역을 담당하며, Claude Sub-Agent 기반으로 Python 스크립트 없이 프롬프트 기반 완전 자동화를 구현했습니다. 위메이드의 "AI를 통한 전체 서비스의 데이터 시스템 최적화" 목표에 기여할 수 있는 아키텍처 설계 경험입니다.

### 2. 온톨로지 기반 데이터 모델링: Neo4j 그래프 DB와 4M2E 관계 정의

AMS 프로젝트에서 Neo4j 그래프 DB를 활용하여 4M2E(Man, Machine, Material, Method, Environment, Energy) 관계를 정의하고 온톨로지 기반 관계 분석을 수행했습니다. 확률 최적화 결과를 분석 온톨로지 형태로 통합하여 이질적인 데이터 소스를 유기적으로 연결했습니다.

이 경험은 위메이드의 "온톨로지 기반 데이터 모델링 설계 및 구현을 바탕으로 신규 DM, 서비스 확장 지원" 요구사항과 직접적으로 매칭됩니다. 게임 데이터의 다양한 소스(유저 행동, 게임 로그, 블록체인 트랜잭션 등)를 온톨로지로 구조화하여 관계를 명확히 정의하고, 서비스 확장 시에도 일관된 데이터 모델을 유지할 수 있습니다.

DPS 프로젝트에서는 모듈화 5층 아키텍처를 설계했습니다. 서비스 및 UI Layer, 통합 및 본체론 Layer (Neo4j 그래프DB), AI 엔진 Layer, 데이터 수집 Layer, 보안 및 관리 Layer로 구성된 이 아키텍처는 대규모 데이터 서비스 운영 환경에서의 경험을 보여줍니다. 위메이드의 "대규모 데이터 서비스 운영 환경 경험" 우대사항을 충족합니다.

### 3. Dual-Tier AI 아키텍처: LLM 비용 87% 절감

Virtual Company Creation Agent 프로젝트에서 Dual-Tier AI 아키텍처를 설계하여 LLM 비용을 87% 절감했습니다. High-Spec AI(추론)와 Low-Spec AI(조회)를 분리하고, "어차피 AI LLM은 앞뒤 주는 것만 잘하면 되니까"라는 인사이트로 특화 중간 DB(GFS, Grape File System)를 만들어서 LLM의 추론 부담을 줄였습니다.

LLM 활용하다보니 온톨로지도 잘 못알아먹고 벡터도 부족하다는 것을 깨달고 특화 중간 DB가 필요하다고 생각해서 만들었습니다. 이 경험은 위메이드의 "검색 엔진 또는 벡터 스토어 사용 경험" 요구사항과 매칭되며, "AI 서비스 전반 아키텍처/모델 전략 수립"에 직접 기여할 수 있습니다.

문제 추적 시간도 90% 이상 단축했습니다. 특화 중간 DB를 통해 AI가 그때그때 추론하면 리소스도 많이 먹고 계속 변동되고 문제가 생겨도 왜인지 추적이 안되는 문제를 해결했습니다. 위메이드의 "AI를 이용한 운영 자동화, 데이터 품질 관리, 이상탐지, 로그 분석, 알림 서비스 개발" 요구사항에 부합하는 경험입니다.

### 4. 자연어 처리: BERT 기반 NLP와 자연어 파싱
