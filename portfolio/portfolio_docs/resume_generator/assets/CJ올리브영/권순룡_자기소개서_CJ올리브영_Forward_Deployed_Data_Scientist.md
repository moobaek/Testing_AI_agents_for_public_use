# 권순룡 자기소개서 - CJ올리브영 Forward Deployed Data Scientist

## 상세경력기술서 (직무 관련 경험/성과 등)

5년간 한솔코에버 연구소에서 Forward Deployed Data Scientist로서 현장 문제를 발굴하고 AI 솔루션으로 구현하여 비즈니스 임팩트를 만들어낸 경험을 쌓았습니다. 특히 제조 현장에서 "기술이 아닌 문제에서 출발해 솔루션을 정의"하는 접근 방식을 통해 실제 비즈니스 가치를 창출하는 프로젝트들을 수행했습니다. 올리브영 AI전략팀의 "오프라인 매장부터 온라인 플랫폼까지 현장에 직접 나가 pain point를 발굴하고, AI솔루션으로 구현하여 비지니스 임팩트를 만들어내는" 목표와 정확히 일치하는 경험을 보유하고 있습니다.

**LLM API, 클라우드 AI 서비스 활용 경험**

FMEA 자동화 생성 시스템에서는 Claude Sub-Agent 기반 Multi-Agent Workflow를 구축하여 8개 독립 Sub-Agent가 협업하는 시스템을 설계했습니다. 이 프로젝트의 시작은 제조 현장에서 FMEA(Failure Mode and Effects Analysis) 문서 작성에 소요되는 시간과 복잡성 문제를 해결하고자 하는 비즈니스 니즈에서 출발했습니다. 기술적 접근이 아닌 현장의 실제 문제(리스크 분석의 복잡성, 시간 소모, 전문가 의존성)에서 출발하여 AI 솔루션으로 구조화했습니다.

Master Orchestrator를 설계하여 Phase 0~5 자동화 워크플로우를 완전 구현했으며, Claude Code Task tool을 활용하여 복잡한 비즈니스 프로세스를 AI 솔루션으로 구조화했습니다. 각 Sub-Agent는 R&D, Mfg, QA 등 전문 영역을 담당하며, Master Orchestrator가 전체 워크플로우를 조율합니다. Phase 0에서는 초기 데이터 수집 및 분석, Phase 1에서는 위험 요소 식별, Phase 2에서는 위험도 평가, Phase 3에서는 대응 방안 수립, Phase 4에서는 검증 및 최적화, Phase 5에서는 최종 문서 생성까지 전 과정을 자동화했습니다.

이 프로젝트에서 오프라인 현장의 pain point를 발굴하고, AI 솔루션으로 구현하여 비즈니스 임팩트를 만들어낸 경험은 올리브영의 "오프라인 매장부터 온라인 플랫폼까지 현장에 직접 나가 pain point를 발굴하고, AI솔루션으로 구현하여 비지니스 임팩트를 만들어내는" 목표와 정확히 일치합니다. 특히 AIAG & VDA FMEA 표준을 준수하면서도 실제 현장의 요구사항을 반영한 범용 리스크 분석 시스템을 구축한 것은 기술적 완성도와 비즈니스 가치를 동시에 추구한 사례로 평가받고 있습니다.

프롬프트 평가 엔진(AI Gatekeeper)에서는 Claude Sub-Agent 기반 프롬프트 평가 시스템을 구축하여 25개+ 프롬프트를 전수 평가하는 시스템을 개발했습니다. 이 프로젝트의 배경은 AI 생성 프롬프트의 품질을 보장하기 위한 체계적인 평가 시스템이 필요하다는 문제 인식에서 출발했습니다. 모든 AI 생성물의 '입구'를 통제하는 심사관 역할을 수행하며, AI가 생성한 프롬프트를 다른 AI가 평가하는 이중 검증(Double-Check) 시스템을 설계하여 환각(Hallucination)을 방지했습니다.

평가 시스템은 3가지 핵심 차원(Quality, Consistency, Cost)을 기준으로 작동하며, 각 차원별로 세부 메트릭을 정의했습니다. Quality 차원에서는 구조적 완성도(Structural Completeness), 정확성(Correctness), 관련성(Relevancy), 톤(Tone) 등을 평가하고, Consistency 차원에서는 역할별 일관성, 스타일 일관성 등을 평가하며, Cost 차원에서는 토큰 사용량, API 호출 비용 등을 평가합니다. MLOps Priority Matrix 기반 가중치 시스템을 통해 각 메트릭의 중요도를 동적으로 조정하며, 17가지 역할별 동적 가중치를 적용하여 다양한 사용자 시나리오에 맞는 평가를 수행합니다. 이 경험을 통해 LLM API를 활용한 실무 시스템 구축 능력을 확보했으며, 특히 비용 효율성과 품질 보장을 동시에 추구하는 방법론을 체득했습니다.

Virtual Company Creation Agent에서는 Claude Agent와 Dual-Tier AI 아키텍처를 통해 최대 87% 비용 절감을 달성했습니다. 이 프로젝트의 핵심 아이디어는 "직원 225명 대신 빈 책상 225개 + 천재 직원 1명"이라는 개념으로, Decoupled Intelligence Architecture (지능과 상태의 분리)를 통해 리소스 효율성을 극대화했습니다. 225개의 빈 책상(포도송이/Grape Cluster)은 평소 Dormant 상태로 유지비 0원을 유지하며, 1명의 슈퍼 AI(거대 에이전트)가 필요한 순간 특정 책상으로 순간이동(Docking)하여 O(1) 리소스로 O(N) 스케일링을 달성했습니다.

Vector DB와 GFS (Grape File System)를 연동하여 AI 없이도 데이터 접근이 가능한 파일 기반 NoSQL 구조를 구축했으며, PostgreSQL-Inspired 기능(WAL, MVCC, Index, Vacuum)으로 엔터프라이즈급 데이터 무결성을 보장했습니다. 7단계 Chain Workflow (Chain 01~07: Foundation → Organization → Agents → System Orchestrator → Protocol → Assembly → Crystallization)를 통해 복잡한 비즈니스 프로세스를 구조화했으며, 14 Layer 온톨로지 좌표 체계 (Strategic/Structural/Functional/Operational/Protocol)를 통해 225개 서브시스템을 효율적으로 관리했습니다. 이 프로젝트를 통해 클라우드 AI 서비스를 효율적으로 활용하는 방법을 체득했으며, 특히 비용 최적화와 성능 보장을 동시에 추구하는 아키텍처 설계 능력을 확보했습니다.

**RAG, Prompt Engineering 전문성**

프롬프트 평가 엔진에서는 3가지 핵심 차원(Quality, Consistency, Cost) 평가 체계와 MLOps Priority Matrix 기반 가중치 시스템을 구축했습니다. 특히 17가지 역할별 동적 가중치를 적용하여 다양한 사용자 시나리오에 맞는 Prompt 구조를 설계했으며, 반복·종료·예외 제어를 포함한 구조화된 Prompt 시스템을 구현했습니다. 평가 프로세스는 Role Inference → Metrics Calculation → Consolidation → Report Generation → Translation의 5단계로 구성되며, 각 단계에서 품질 검증을 수행합니다.

Quality 차원에서는 Structural Completeness (40%), Correctness (30%), Relevancy (20%), Tone (10%)의 가중치를 적용하여 프롬프트의 구조적 완성도, 정확성, 관련성, 톤을 평가합니다. Consistency 차원에서는 역할별 일관성, 스타일 일관성, 용어 일관성 등을 평가하며, Cost 차원에서는 토큰 사용량, API 호출 비용, 처리 시간 등을 평가합니다. 17가지 역할별 동적 가중치는 각 역할의 특성에 맞게 가중치를 조정하여, 예를 들어 개발자 역할에서는 Correctness 가중치를 높이고, 기획자 역할에서는 Relevancy 가중치를 높이는 방식으로 작동합니다.

이 경험을 통해 Prompt를 단순 텍스트가 아닌 Agent 동작 로직의 일부로 설계하는 전문성을 확보했습니다. 특히 반복·종료·예외 제어를 포함한 구조화된 Prompt 시스템은 Agent의 실행 흐름을 명확히 정의하고, 예상치 못한 상황에 대응할 수 있는 견고한 시스템을 구축하는 데 핵심적인 역할을 했습니다.

Virtual Company Creation Agent에서는 Vector DB 기반 RAG 시스템을 구축했습니다. 7단계 Chain Workflow와 14 Layer 온톨로지 좌표 체계를 통해 복잡한 비즈니스 프로세스를 구조화했으며, 225개 서브시스템을 효율적으로 관리하는 시스템을 설계했습니다. RAG 시스템의 핵심은 Vector DB를 통해 관련 문서를 검색하고, 검색된 문서를 컨텍스트로 활용하여 LLM이 정확한 답변을 생성하도록 하는 것입니다.

GFS (Grape File System)를 통해 AI 없이도 데이터 접근이 가능한 파일 기반 NoSQL 구조를 구축하여 비용 87% 절감을 달성했습니다. 단순 조회 작업은 AI를 사용하지 않고 파일 시스템에서 직접 수행하며, 복잡한 추론 작업만 High-Spec AI를 사용하는 방식으로 비용을 최적화했습니다. 이 프로젝트를 통해 RAG 시스템의 설계 및 구축 능력을 확보했으며, 특히 비용 효율성과 성능을 동시에 추구하는 방법론을 체득했습니다.

FMEA 자동화 생성 시스템에서는 Prompt 구조 설계 및 운영 기준을 정립했습니다. AIAG & VDA FMEA 표준 기반 범용 리스크 분석 시스템에서 Prompt를 통해 복잡한 워크플로우를 구조화하고, 각 Sub-Agent의 역할과 책임을 명확히 정의했습니다. 각 Sub-Agent는 자신의 전문 영역에 맞는 Prompt를 받아 작업을 수행하며, Master Orchestrator는 전체 워크플로우를 조율하는 Prompt를 사용합니다.

Prompt 구조는 역할 정의, 입력 데이터 형식, 출력 데이터 형식, 예외 처리 방법, 종료 조건 등을 포함하여 구조화되어 있습니다. 반복 작업의 경우 최대 반복 횟수와 종료 조건을 명확히 정의하고, 예외 상황 발생 시 처리 방법을 사전에 정의하여 시스템의 안정성을 보장했습니다. 이 경험을 통해 Prompt Engineering의 실무 적용 능력을 확보했으며, 특히 복잡한 비즈니스 프로세스를 Prompt로 구조화하는 방법론을 체득했습니다.

**ML/DL 모델링 및 데이터 파이프라인 설계**

AMS 프로젝트에서는 베이지안 네트워크 기반 이상 탐지 모델을 개발하여 93.7%의 정확도를 달성했습니다. 이 프로젝트는 제조 현장에서 발생하는 이상 상황을 사전에 탐지하여 불량률을 감소시키고자 하는 비즈니스 니즈에서 출발했습니다. 확률 최적화(경사하강법)를 통한 이상상황 확률 네트워크를 구축했으며, 시계열 데이터를 분석하여 이상 패턴을 학습하는 모델을 개발했습니다.

8단계 시계열 데이터 파이프라인을 설계하여 데이터 전처리부터 모델 학습, 예측, 결과 시각화까지 전 과정을 자동화했습니다. 1단계에서는 원시 데이터 수집, 2단계에서는 데이터 전처리 및 정제, 3단계에서는 특징 추출, 4단계에서는 데이터 정규화, 5단계에서는 모델 학습, 6단계에서는 모델 평가 및 검증, 7단계에서는 예측 수행, 8단계에서는 결과 시각화 및 대시보드 업데이트를 수행합니다. 각 단계는 독립적으로 작동하며, 이전 단계의 결과를 다음 단계의 입력으로 사용하는 파이프라인 구조를 가지고 있습니다.

이 프로젝트를 통해 ML/DL 모델링과 데이터 파이프라인 설계 능력을 확보했으며, GS 인증 1등급을 취득하고 세아특수강과 포미아에 정식 납품했습니다. 특히 이상탐지율 93.7%는 실질적 정확도 60~70%를 고려한 수치로, 데이터의 한계를 고려한 현실적인 성과입니다. 학술 논문 2건을 발표하여 기술적 전문성을 학술적으로 뒷받침했습니다.

DPS 프로젝트에서는 5층 아키텍처와 Microservices 기반 데이터 파이프라인을 구축했습니다. 1층은 데이터 수집 계층, 2층은 데이터 저장 계층, 3층은 데이터 처리 계층, 4층은 데이터 분석 계층, 5층은 데이터 시각화 계층으로 구성되어 있으며, 각 계층은 Microservices로 구현되어 독립적으로 확장 가능합니다. Neo4j 그래프DB를 활용한 데이터 통합 시스템을 설계했으며, 4M2E (Man, Machine, Material, Method, Environment, Energy) 관계를 정의하여 제조 공정의 복잡한 관계를 구조화했습니다.

이 프로젝트를 통해 대규모 데이터 파이프라인 설계 및 구축 능력을 확보했으며, 세아특수강과 포미아에 정식 납품했습니다. 특히 5층 아키텍처는 제조 현장의 다양한 데이터 소스를 통합하고, 실시간으로 처리 및 분석할 수 있는 확장 가능한 구조를 제공합니다. 학술 논문을 발표하여 기술적 전문성을 학술적으로 뒷받침했습니다.

품질 예측 AI 엔진 프로젝트에서는 다수 업체(사출, 도정, 금형 등) 품질 예측 AI 엔진을 개발 및 고도화했습니다. 각 업체의 공정 특성에 맞게 모델을 커스터마이징했으며, 불량률 감소 성과를 달성했습니다. 사출 공정에서는 사출 온도, 압력, 속도 등의 파라미터를 입력으로 받아 품질을 예측하는 모델을 개발했으며, 도정 공정에서는 도료 두께, 건조 시간 등의 파라미터를 입력으로 받아 품질을 예측하는 모델을 개발했습니다. 금형 공정에서는 금형 온도, 압력 등의 파라미터를 입력으로 받아 품질을 예측하는 모델을 개발했습니다.

이 경험을 통해 ML/DL 모델링의 실무 적용 능력을 확보했으며, 특히 다양한 도메인에 적용 가능한 범용 모델과 도메인 특화 모델을 구분하여 설계하는 능력을 체득했습니다. 각 업체의 특성에 맞게 모델을 커스터마이징하는 과정에서 비개발 직군과의 협업 경험도 쌓았습니다.

**비개발 직군과 협업하여 요구사항을 도출한 경험**

PM Agent에서는 사업 관리의 전체 라이프사이클을 관장하며 비개발 직군과 협업하여 요구사항을 도출했습니다. 이 프로젝트의 시작은 사업 관리 업무의 복잡성과 시간 소모 문제를 해결하고자 하는 비즈니스 니즈에서 출발했습니다. 계약서/과업지시서 분석을 통한 Risk Management, 회의록 분석을 통한 Schedule Tracking, 누락된 문서나 데이터 파편화를 방지하는 Integrity Check 등 비즈니스 문제 중심 솔루션을 설계했습니다.

Risk Management 기능은 계약서/과업지시서 내 독소 조항을 자동으로 추출하고, 리스크 수준을 평가하여 사업 관리자에게 알림을 제공합니다. 계약서의 각 조항을 분석하여 불리한 조건, 위험 요소, 법적 리스크 등을 식별하고, 리스크 수준을 High, Medium, Low로 분류합니다. 사업 관리자는 리스크가 높은 조항에 대해 사전에 대응 방안을 수립할 수 있습니다.

Schedule Tracking 기능은 회의록을 분석하여 타임라인을 자동으로 현행화합니다. 회의록에서 일정 변경, 마일스톤 조정, 지연 사항 등을 자동으로 추출하고, 프로젝트 타임라인을 업데이트합니다. 이를 통해 수동으로 타임라인을 관리하는 시간을 절약하고, 정확한 일정 관리를 가능하게 합니다.

Integrity Check 기능은 누락된 문서나 데이터 파편화를 방지합니다. 프로젝트 진행 과정에서 필요한 문서들이 모두 생성되었는지 확인하고, 문서 간 일관성을 검증합니다. 데이터 파편화를 방지하기 위해 중앙 집중식 데이터 저장소를 구축하고, 데이터 무결성을 보장하는 시스템을 설계했습니다.

이 경험을 통해 비개발 직군과의 효과적인 협업 능력을 확보했으며, 특히 비즈니스 문제를 기술적 솔루션으로 구조화하는 능력을 체득했습니다. 사업 관리자, 기획자, 컨설턴트 등 다양한 비개발 직군과 협업하면서 그들의 요구사항을 정확히 이해하고, AI 솔루션으로 구현하는 과정에서 소통 능력과 문제 해결 능력을 향상시켰습니다.

Business Document Generator에서는 요구조건 문서 파싱, 포트폴리오 스마트 매칭, 발주처 유형별 페르소나 적용, WBS 세부화, PDF 자동 변환 등 End-to-End 워크플로우를 구축했습니다. 이 프로젝트의 시작은 사업계획서/제안서/착수보고서 작성에 소요되는 시간과 일관성 문제를 해결하고자 하는 비즈니스 니즈에서 출발했습니다.

발주처 유형별 페르소나 적용 (정부/민간/공공기관)을 통해 다양한 비즈니스 요구사항에 대응하는 시스템을 설계했습니다. 정부 기관의 경우 공공성, 투명성, 예산 효율성 등을 강조하는 페르소나를 적용하고, 민간 기관의 경우 수익성, 혁신성, 시장 경쟁력 등을 강조하는 페르소나를 적용하며, 공공기관의 경우 공공성과 수익성을 균형있게 강조하는 페르소나를 적용합니다. 각 페르소나에 맞게 문서의 톤, 구조, 강조 사항 등을 조정하여 발주처의 요구사항에 맞는 문서를 생성합니다.

포트폴리오 스마트 매칭 기능은 발주처의 요구사항과 포트폴리오의 프로젝트를 매칭하여 관련성 높은 프로젝트를 선별합니다. 요구사항 문서를 분석하여 키워드를 추출하고, 포트폴리오의 각 프로젝트와 매칭 점수를 계산하여 상위 프로젝트를 선별합니다. 매칭 점수는 기술 스택 일치도, 도메인 일치도, 경험 연관성 등을 종합하여 계산합니다.

이 경험을 통해 비개발 직군의 요구사항을 정확히 이해하고 AI 솔루션으로 구조화하는 능력을 확보했습니다. 특히 발주처 유형별 페르소나 적용을 통해 다양한 비즈니스 요구사항에 대응하는 유연한 시스템을 설계하는 능력을 체득했습니다.

테크웰, 신성오토텍 등 현장 컨설팅 프로젝트에서는 오프라인 현장에 직접 나가 pain point를 발굴하고, AI 솔루션으로 구현하여 비즈니스 임팩트를 만들어냈습니다. 테크웰 프로젝트에서는 전력량 측정계 설치, 전력 모니터링 프로그램을 개발하여 에너지 효율화를 지원했습니다. 신성오토텍 프로젝트에서는 사출기 데이터 수집, 사출 데이터 모니터링 프로그램을 개발하여 품질 관리 및 불량률 감소를 지원했습니다.

현장에 직접 나가 사용자 인터뷰를 진행하고, 실제 운영 환경을 관찰하며, 문제점을 발굴하는 과정에서 Forward Deployed Data Scientist로서의 핵심 역량을 체득했습니다. 기술적 솔루션을 제안하기 전에 비즈니스 문제를 정확히 이해하고, 사용자의 니즈를 파악하는 것이 중요하다는 것을 배웠습니다. 이 경험을 통해 현장 문제 해결 능력을 확보했으며, 특히 오프라인 현장의 복잡한 상황을 이해하고 AI 솔루션으로 구조화하는 능력을 향상시켰습니다.

**기술이 아닌 문제에서 출발해 솔루션을 정의한 경험**

FMEA 자동화 생성 시스템에서는 AIAG & VDA FMEA 표준 기반 범용 리스크 분석 시스템을 구축했습니다. 기술적 접근이 아닌 현장의 실제 문제(리스크 분석의 복잡성, 시간 소모, 전문가 의존성)에서 출발하여 AI 솔루션으로 구조화했습니다. 제조 현장에서 FMEA 문서 작성은 매우 복잡하고 시간이 많이 소요되는 작업이며, 전문가의 지식과 경험이 필요한 작업입니다. 이러한 문제를 해결하기 위해 AI 솔루션을 설계했습니다.

Master Orchestrator를 설계하여 8개 Sub-Agent가 협업하는 시스템을 구축했으며, Phase 0~5 자동화 워크플로우를 완전 구현했습니다. 각 Sub-Agent는 자신의 전문 영역에 맞는 작업을 수행하며, Master Orchestrator가 전체 워크플로우를 조율합니다. 이 시스템을 통해 FMEA 문서 작성 시간을 대폭 단축하고, 전문가의 지식을 체계적으로 활용할 수 있게 되었습니다.

PM Agent에서는 사업 관리의 실제 문제(Risk Management, Schedule Tracking, Integrity Check)에서 출발하여 MCP 기반 자동화 시스템을 설계했습니다. 사업 관리 업무는 계약서 분석, 일정 관리, 문서 관리 등 다양한 작업이 복잡하게 얽혀 있으며, 수동으로 관리하기에는 시간과 노력이 많이 소요됩니다. 이러한 문제를 해결하기 위해 AI 솔루션을 설계했습니다.

계약서/과업지시서 내 독소 조항 자동 추출, 회의록 분석을 통한 타임라인 자동 현행화, 누락된 문서나 데이터 파편화 방지 등 비즈니스 문제 중심 솔루션을 구현했습니다. 이 시스템을 통해 사업 관리 업무의 효율성을 향상시키고, 리스크를 사전에 식별하여 대응할 수 있게 되었습니다.

Business Document Generator에서는 사업계획서/제안서/착수보고서 작성의 시간 소모와 일관성 문제에서 출발하여 자동 생성 시스템을 설계했습니다. 이러한 문서 작성은 매우 시간이 많이 소요되는 작업이며, 일관성 있는 문서를 작성하기 위해서는 많은 노력이 필요합니다. 이러한 문제를 해결하기 위해 AI 솔루션을 설계했습니다.

요구조건 문서 파싱, 포트폴리오 스마트 매칭, 발주처 유형별 페르소나 적용, WBS 세부화, PDF 자동 변환 등 End-to-End 워크플로우를 구축했습니다. 이 시스템을 통해 문서 작성 시간을 대폭 단축하고, 일관성 있는 문서를 자동으로 생성할 수 있게 되었습니다.

**AI 서비스의 기획부터 개발까지 End-to-End 주도**

FMEA 자동화 생성 시스템에서는 Master Orchestrator를 설계하여 기획부터 개발까지 End-to-End로 주도했습니다. AIAG & VDA FMEA 표준 기반 범용 리스크 분석 시스템의 요구사항 분석부터 Claude Sub-Agent 기반 Multi-Agent Workflow 설계, 8개 Sub-Agent 협업 구조 구현, Phase 0~5 자동화 워크플로우 완전 구현까지 전 과정을 주도했습니다.

요구사항 분석 단계에서는 제조 현장의 실제 문제를 파악하고, FMEA 표준을 준수하면서도 현장의 요구사항을 반영한 시스템을 설계했습니다. 시스템 설계 단계에서는 Master Orchestrator와 8개 Sub-Agent의 역할과 책임을 명확히 정의하고, 각 Sub-Agent 간의 통신 프로토콜을 설계했습니다. 개발 단계에서는 Claude Sub-Agent를 활용하여 각 Sub-Agent를 구현하고, Master Orchestrator를 통해 전체 워크플로우를 조율하는 시스템을 구축했습니다. 테스트 및 검증 단계에서는 실제 제조 현장 데이터를 활용하여 시스템을 검증하고, 성능을 최적화했습니다.

Business Document Generator에서는 요구조건 문서 파싱부터 포트폴리오 스마트 매칭, 발주처 유형별 페르소나 적용, WBS 세부화, PDF 자동 변환까지 End-to-End 워크플로우를 구축했습니다. PM 통합 검증 시스템을 통해 품질을 보장했습니다. 각 단계에서 발생하는 문제를 해결하고, 사용자 피드백을 반영하여 시스템을 지속적으로 개선했습니다.

AMS 프로젝트에서는 AI 종합 플랫폼 개발 총괄 PM으로서 기획부터 개발까지 End-to-End로 주도했습니다. 베이지안 네트워크 기반 이상 탐지 모델 개발, 8단계 시계열 데이터 파이프라인 설계 및 구축, GS 인증 1등급 취득, 세아특수강과 포미아에 정식 납품까지 전 과정을 주도했습니다. 프로젝트 관리, 기술 개발, 품질 관리, 고객 대응 등 다양한 역할을 수행하면서 End-to-End 개발 능력을 확보했습니다.

2024.12 한국유체기계학회에서 "설비 이상상태 기반 최적 공정 데이터 추론 및 위험/안전 관리 최적 자동화"를 발표하여 AMS 프로젝트의 실시간 이상 상태 기반 위험 관리 알고리즘의 유효성을 검증했습니다.

올리브영 AI전략팀의 Forward Deployed Data Scientist 포지션을 잘 수행할 수 있다고 생각하는 이유는 제가 5년간 쌓아온 "기술이 아닌 문제에서 출발해 솔루션을 정의"하는 경험과 "오프라인 현장부터 온라인 플랫폼까지 현장에 직접 나가 pain point를 발굴하고, AI솔루션으로 구현하여 비지니스 임팩트를 만들어내는" 전문성이 올리브영의 요구사항과 정확히 일치하기 때문입니다. 특히 올리브영이 추구하는 "Forward Deployed"라는 개념은 사무실에서 모델링만 하는 것이 아니라, 현장에 직접 나가 문제를 발굴하고 해결하는 것을 의미하는데, 제가 테크웰, 신성오토텍 등 현장 컨설팅 프로젝트에서 쌓은 경험이 바로 이러한 역량을 보여줍니다.

**LLM API, 클라우드 AI 서비스 활용 전문성**

제가 보유한 LLM API, 클라우드 AI 서비스 활용 전문성은 올리브영의 "상용 AI 솔루션을 활용한 개발" 요구사항을 충족합니다. FMEA 자동화 생성 시스템에서 Claude Sub-Agent 기반 Multi-Agent Workflow를 구축하여 8개 독립 Sub-Agent가 협업하는 시스템을 설계한 경험, 프롬프트 평가 엔진에서 25개+ 프롬프트를 전수 평가하는 AI Gatekeeper 시스템을 개발한 경험, Virtual Company Creation Agent에서 Dual-Tier AI 아키텍처를 통해 최대 87% 비용 절감을 달성한 경험을 통해 LLM API와 클라우드 AI 서비스를 효율적으로 활용하는 능력을 확보했습니다.

특히 Virtual Company Creation Agent에서 구현한 Dual-Tier AI 아키텍처는 High-Spec AI (추론)와 Low-Spec AI (조회)를 분리하여 비용 효율성을 극대화한 사례로, 올리브영의 "클라우드 AI 서비스 활용" 요구사항에 직접적으로 기여할 수 있습니다. 단순 조회 작업은 Low-Spec AI를 사용하여 비용을 절감하고, 복잡한 추론 작업만 High-Spec AI를 사용하는 방식으로 전체 비용을 최적화했습니다. 또한 GFS (Grape File System)를 통해 AI 없이도 데이터 접근이 가능한 파일 기반 NoSQL 구조를 구축하여 비용 87% 절감을 달성한 경험은 올리브영의 비즈니스 임팩트 창출 목표와 일치합니다.

FMEA 자동화 생성 시스템에서 Claude Sub-Agent를 활용한 Multi-Agent Workflow 구축 경험은 올리브영의 "상용 AI 솔루션을 활용한 개발" 요구사항에 직접적으로 기여할 수 있습니다. Claude Code Task tool을 활용하여 복잡한 비즈니스 프로세스를 AI 솔루션으로 구조화했으며, 8개 Sub-Agent가 각자의 전문 영역에서 작업을 수행하고, Master Orchestrator가 전체 워크플로우를 조율하는 시스템을 구축했습니다. 이 경험을 통해 상용 LLM API를 활용하여 실제 비즈니스 문제를 해결하는 능력을 확보했습니다.

프롬프트 평가 엔진에서 25개+ 프롬프트를 전수 평가하는 AI Gatekeeper 시스템을 개발한 경험은 올리브영의 "LLM API, 클라우드 AI 서비스 활용 경험" 요구사항을 충족합니다. 모든 AI 생성물의 '입구'를 통제하는 심사관 역할을 수행하며, AI가 생성한 프롬프트를 다른 AI가 평가하는 이중 검증(Double-Check) 시스템을 설계하여 환각(Hallucination)을 방지했습니다. 이 경험을 통해 LLM API를 활용한 품질 관리 시스템을 구축하는 능력을 확보했습니다.

**RAG, Prompt Engineering 전문성**

제가 보유한 RAG, Prompt Engineering 전문성은 올리브영의 우대사항인 "RAG, Prompt Engineering 경험"을 충족합니다. 프롬프트 평가 엔진에서 3가지 핵심 차원(Quality, Consistency, Cost) 평가 체계와 MLOps Priority Matrix 기반 가중치 시스템을 구축한 경험, 17가지 역할별 동적 가중치를 적용하여 다양한 사용자 시나리오에 맞는 Prompt 구조를 설계한 경험, Virtual Company Creation Agent에서 Vector DB 기반 RAG 시스템을 구축한 경험을 통해 RAG와 Prompt Engineering의 실무 적용 능력을 확보했습니다.

특히 프롬프트 평가 엔진에서 구현한 Prompt를 단순 텍스트가 아닌 Agent 동작 로직의 일부로 설계하는 접근 방식은 올리브영의 "Prompt를 단순 텍스트가 아닌 Agent 동작 로직의 일부로 다뤄본 경험" 요구사항을 충족합니다. Prompt 구조는 역할 정의, 입력 데이터 형식, 출력 데이터 형식, 예외 처리 방법, 종료 조건 등을 포함하여 구조화되어 있으며, 반복·종료·예외 제어를 포함한 구조화된 Prompt 시스템을 구현한 경험은 올리브영의 "Agent 실행 흐름을 구조화하여 설계·구현할 수 있는 역량 (반복·종료·예외 제어 포함)" 요구사항과 일치합니다.

Virtual Company Creation Agent에서 Vector DB 기반 RAG 시스템을 구축한 경험은 올리브영의 "RAG, Prompt Engineering 경험" 우대사항을 충족합니다. 7단계 Chain Workflow와 14 Layer 온톨로지 좌표 체계를 통해 복잡한 비즈니스 프로세스를 구조화했으며, Vector DB를 통해 관련 문서를 검색하고, 검색된 문서를 컨텍스트로 활용하여 LLM이 정확한 답변을 생성하도록 하는 시스템을 구축했습니다. GFS (Grape File System)를 통해 AI 없이도 데이터 접근이 가능한 파일 기반 NoSQL 구조를 구축하여 비용 87% 절감을 달성한 경험은 올리브영의 비즈니스 임팩트 창출 목표와 일치합니다.

FMEA 자동화 생성 시스템에서 Prompt 구조 설계 및 운영 기준을 정립한 경험은 올리브영의 "RAG, Prompt Engineering 경험" 우대사항을 충족합니다. AIAG & VDA FMEA 표준 기반 범용 리스크 분석 시스템에서 Prompt를 통해 복잡한 워크플로우를 구조화하고, 각 Sub-Agent의 역할과 책임을 명확히 정의했습니다. 각 Sub-Agent는 자신의 전문 영역에 맞는 Prompt를 받아 작업을 수행하며, Master Orchestrator는 전체 워크플로우를 조율하는 Prompt를 사용합니다.

**ML/DL 모델링 및 데이터 파이프라인 설계 전문성**

제가 보유한 ML/DL 모델링 및 데이터 파이프라인 설계 전문성은 올리브영의 "ML/DL 모델링에 대한 이해"와 "데이터 파이프라인 설계 경험" 요구사항을 충족합니다. AMS 프로젝트에서 베이지안 네트워크 기반 이상 탐지 모델을 개발하여 93.7%의 정확도를 달성한 경험, 8단계 시계열 데이터 파이프라인을 설계하여 데이터 전처리부터 모델 학습, 예측, 결과 시각화까지 전 과정을 자동화한 경험, DPS 프로젝트에서 5층 아키텍처와 Microservices 기반 데이터 파이프라인을 구축한 경험을 통해 ML/DL 모델링과 데이터 파이프라인 설계 능력을 확보했습니다.

특히 AMS 프로젝트에서 구현한 8단계 시계열 데이터 파이프라인은 데이터 전처리, 특징 추출, 모델 학습, 예측, 결과 시각화까지 전 과정을 자동화한 사례로, 올리브영의 "데이터 파이프라인 설계 경험" 요구사항에 직접적으로 기여할 수 있습니다. 1단계에서는 원시 데이터 수집, 2단계에서는 데이터 전처리 및 정제, 3단계에서는 특징 추출, 4단계에서는 데이터 정규화, 5단계에서는 모델 학습, 6단계에서는 모델 평가 및 검증, 7단계에서는 예측 수행, 8단계에서는 결과 시각화 및 대시보드 업데이트를 수행합니다. 각 단계는 독립적으로 작동하며, 이전 단계의 결과를 다음 단계의 입력으로 사용하는 파이프라인 구조를 가지고 있습니다.

또한 Neo4j 그래프DB를 활용한 데이터 통합 시스템 설계 경험은 올리브영의 데이터 구조화 및 분석 능력 요구사항을 충족합니다. DPS 프로젝트에서 4M2E (Man, Machine, Material, Method, Environment, Energy) 관계를 정의하여 제조 공정의 복잡한 관계를 구조화했으며, 그래프 기반 쿼리를 통해 복잡한 관계 분석을 수행했습니다. 이 경험을 통해 대규모 데이터를 구조화하고 분석하는 능력을 확보했습니다.

품질 예측 AI 엔진 프로젝트에서 다수 업체(사출, 도정, 금형 등) 품질 예측 AI 엔진을 개발 및 고도화한 경험은 올리브영의 "ML/DL 모델링에 대한 이해" 요구사항을 충족합니다. 각 업체의 공정 특성에 맞게 모델을 커스터마이징했으며, 불량률 감소 성과를 달성했습니다. 이 경험을 통해 다양한 도메인에 적용 가능한 ML/DL 모델을 개발하는 능력을 확보했습니다.

**비개발 직군과 협업하여 요구사항을 도출한 경험**

제가 보유한 비개발 직군과 협업하여 요구사항을 도출한 경험은 올리브영의 "비개발 직군과 협업하여 요구사항을 도출한 경험" 요구사항을 충족합니다. PM Agent에서 사업 관리의 전체 라이프사이클을 관장하며 계약서/과업지시서 분석, 회의록 분석을 통한 타임라인 자동 현행화 등 비개발 직군과 협업한 경험, Business Document Generator에서 발주처 유형별 페르소나 적용 (정부/민간/공공기관)을 통해 다양한 비즈니스 요구사항에 대응한 경험, 테크웰, 신성오토텍 등 현장 컨설팅 프로젝트에서 오프라인 현장에 직접 나가 pain point를 발굴하고 AI 솔루션으로 구현한 경험을 통해 비개발 직군과의 효과적인 협업 능력을 확보했습니다.

특히 PM Agent에서 구현한 Risk Management (계약서/과업지시서 내 독소 조항 자동 추출), Schedule Tracking (회의록 분석), Integrity Check (누락된 문서나 데이터 파편화 방지) 등은 비개발 직군의 실제 문제를 AI 솔루션으로 구조화한 사례로, 올리브영의 "현장 사용자 인터뷰 및 문제 정의" 요구사항에 직접적으로 기여할 수 있습니다. 사업 관리자, 기획자, 컨설턴트 등 다양한 비개발 직군과 협업하면서 그들의 요구사항을 정확히 이해하고, AI 솔루션으로 구현하는 과정에서 소통 능력과 문제 해결 능력을 향상시켰습니다.

Business Document Generator에서 발주처 유형별 페르소나 적용 (정부/민간/공공기관)을 통해 다양한 비즈니스 요구사항에 대응한 경험은 올리브영의 "비개발 직군과 협업하여 요구사항을 도출한 경험" 요구사항을 충족합니다. 각 발주처 유형의 특성과 요구사항을 분석하고, 그에 맞는 페르소나를 적용하여 문서를 생성하는 과정에서 비개발 직군과의 협업 경험을 쌓았습니다. 정부 기관의 경우 공공성, 투명성, 예산 효율성 등을 강조하는 페르소나를 적용하고, 민간 기관의 경우 수익성, 혁신성, 시장 경쟁력 등을 강조하는 페르소나를 적용하며, 공공기관의 경우 공공성과 수익성을 균형있게 강조하는 페르소나를 적용합니다.

테크웰, 신성오토텍 등 현장 컨설팅 프로젝트에서 오프라인 현장에 직접 나가 pain point를 발굴하고 AI 솔루션으로 구현한 경험은 올리브영의 "비개발 직군과 협업하여 요구사항을 도출한 경험" 요구사항을 충족합니다. 현장에 직접 나가 사용자 인터뷰를 진행하고, 실제 운영 환경을 관찰하며, 문제점을 발굴하는 과정에서 Forward Deployed Data Scientist로서의 핵심 역량을 체득했습니다. 기술적 솔루션을 제안하기 전에 비즈니스 문제를 정확히 이해하고, 사용자의 니즈를 파악하는 것이 중요하다는 것을 배웠습니다.

**기술이 아닌 문제에서 출발해 솔루션을 정의한 경험**

제가 보유한 "기술이 아닌 문제에서 출발해 솔루션을 정의한 경험"은 올리브영의 핵심 요구사항입니다. FMEA 자동화 생성 시스템에서는 AIAG & VDA FMEA 표준 기반 범용 리스크 분석 시스템의 실제 문제(리스크 분석의 복잡성, 시간 소모, 전문가 의존성)에서 출발하여 Claude Sub-Agent 기반 Multi-Agent Workflow로 구조화했습니다. 기술적 접근이 아닌 현장의 실제 문제에서 출발하여 AI 솔루션을 설계했으며, 이를 통해 실제 비즈니스 가치를 창출했습니다.

PM Agent에서는 사업 관리의 실제 문제(Risk Management, Schedule Tracking, Integrity Check)에서 출발하여 MCP 기반 자동화 시스템을 설계했습니다. 사업 관리 업무는 계약서 분석, 일정 관리, 문서 관리 등 다양한 작업이 복잡하게 얽혀 있으며, 수동으로 관리하기에는 시간과 노력이 많이 소요됩니다. 이러한 문제를 해결하기 위해 AI 솔루션을 설계했으며, 계약서/과업지시서 내 독소 조항 자동 추출, 회의록 분석을 통한 타임라인 자동 현행화, 누락된 문서나 데이터 파편화 방지 등 비즈니스 문제 중심 솔루션을 구현했습니다.
