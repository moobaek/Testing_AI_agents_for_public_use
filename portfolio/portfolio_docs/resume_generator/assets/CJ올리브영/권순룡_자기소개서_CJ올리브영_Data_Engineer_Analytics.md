# 권순룡 자기소개서 - CJ올리브영 Data Engineer (Analytics)

## 지원하게 된 동기(이직사유 포함)와 본인의 강점(주요 성과 창출 사례)

5년간 제조 도메인 데이터 분석 플랫폼을 구축하며 데이터 엔지니어링 전문성을 쌓았습니다. 제조업에서 축적한 데이터 파이프라인 설계와 운영 경험을 커머스 도메인에 적용하여 더 넓은 영향력을 만들고 싶어 CJ올리브영에 지원하게 되었습니다.

제조 도메인에서는 센서·설비·공정 데이터를 다뤘지만, 커머스 도메인에서는 고객행동로그·거래 데이터·마케팅 데이터를 다루게 됩니다. 데이터 소스는 다르지만, "복잡한 로그를 구조화된 지표로 변환하고, 이상을 탐지하며, 품질을 관리하는" 핵심 역량은 동일합니다. CJ올리브영의 "고객행동로그 기반 데이터 모델 설계 및 분석 친화적 파이프라인 관리·최적화" 목표는 AMS와 DPS 프로젝트에서 수행한 작업과 직접적으로 연결됩니다.

**AMS 프로젝트 주요 성과**: 2024년 7월부터 한국산업기술진흥원 과제로 진행한 AMS 프로젝트에서 총괄 PM으로 참여하며, SQL 기반 대규모 데이터 파이프라인을 설계하고 8단계 시계열 데이터 처리 시스템을 구축했습니다. MSSQL Server와 Neo4j를 활용하여 대규모 데이터 가공 및 분석을 수행했으며, 49개 Python 모듈과 연동된 통합 시스템을 개발했습니다. 베이지안 네트워크 기반 품질 관리 시스템으로 이상 탐지 93.7% 정확도를 달성했으며, 피쉬본 다이어그램 자동 생성 기능을 통해 원인-결과 관계를 구조화하고, FMEA 자동화까지 구현했습니다. GS 인증 1등급을 취득했으며, 세아특수강과 포미아에 정식 납품했습니다. 이 프로젝트에서 정립한 "복잡한 로그를 구조화된 원인 그래프로 변환하는 방법"은 CJ올리브영의 고객행동로그 기반 지표 설계에 그대로 대응됩니다.

**DPS 프로젝트 주요 성과**: 2022년 3월부터 중소기업기술정보진흥원 과제로 진행한 DPS 프로젝트에서 총괄 PM으로 참여하며, 5층 아키텍처 기반 데이터 파이프라인을 설계하고 Neo4j 그래프 DB를 활용한 온톨로지 기반 지식 구조를 구축했습니다. 센서·설비·공정·품질 데이터를 한 시스템에서 다루기 위해 수집→저장→가공→분석→서비스 레이어가 분리된 구조로 설계했습니다. 이 프로젝트에서 정립한 "이질적인 로그들을 안정적으로 모으고, 분석 친화적인 구조로 재배치하는 능력"은 CJ올리브영의 웹/앱 로그·거래 데이터를 하나의 파이프라인에서 다루는 구조와 연결됩니다.

**CoCTK 프로젝트 주요 성과**: 2022년 3월부터 중소기업기술정보진흥원 과제로 진행한 CoCTK 프로젝트에서 총괄 PM으로 참여하며, 상관관계 분석 엔진을 개발하여 데이터 정합성을 확보했습니다. 데이터 전처리 및 비용 최적화 엔진을 설계하고, GS 인증 1등급을 취득했습니다.

**오웰(일본) 프로젝트 주요 성과**: 2020년부터 2024년까지 4년간 일본 글로벌 기업 O-WELL과 협업하며 인과 관계 다이어그램 AI 엔진을 개발했습니다. 패턴 최적 선택과 계층 클러스터링을 종합한 관계 구조를 생성하여 전사적 DX 가속화를 지원했습니다. 이 프로젝트에서 사용한 관계 구조·텍소노미 설계 방식이, AMS의 지표 구조와 CoCTK의 분석 항목 정의에 공통된 기준을 제공했습니다. 이 경험을 바탕으로 CJ올리브영의 텍소노미 설계·운영에 기여할 수 있습니다.

**Evaluation_Framework 주요 성과**: 2024년 1월부터 내부 개발로 진행한 Evaluation_Framework에서 49개 Python 모듈과 298개 문서를 전수 검사하는 자동화 평가 시스템을 구축하여 데이터 정합성을 보장했습니다. 6가지 관점 평가 시스템을 통해 전체 시스템 품질을 보장하는 체계를 마련했습니다. 이 경험을 바탕으로 CJ올리브영의 지표 품질 검증 업무에 기여할 수 있습니다.

**전체 성과 요약**: GS 인증 1등급 2개(AMS, CoCTK)를 취득했으며, 세아특수강과 포미아에 정식 납품했습니다. 논문 10편을 발표하여(2022-2025) 기술적 신뢰도를 확보했습니다.

제조 도메인에서 쌓은 데이터 품질 관리 경험을 커머스 도메인에 적용하여, CJ올리브영의 데이터 리터러시 강화와 표준화 체계 구축에 기여하고 싶습니다. 다양한 이해관계자와의 협업 경험과 총괄 PM 역할 수행 경험을 바탕으로, CJ올리브영의 데이터 분석 팀과 원활히 협업하며 고객행동분석 지표 정의 및 관리 체계를 위한 텍소노미 설계·운영에 기여하겠습니다.
