#### 1.2 온톨로지/구조화/정보화 (5년 핵심 역량)

**기술 철학**:
> "모델보다 데이터, 데이터보다 정보, 지식구조를 정리하는 현장친화적 연구원"

**5년간 진화 흐름**:
```
2020: FBS (피쉬본 = 구조화된 인과관계)
  ↓
2021-2023: 패턴 정보화, 에너지 패턴 분석, CoCTK
  ↓
2024-2025: AMS (확률 네트워크 = 구조화된 확률 관계)
  ↓
2025-2026: LLM 에이전트 (온톨로지 정보화의 연장선)
```

**구체적 구현 사례**:
- Neo4j 기반 RAG 시스템, 4M2E 관계 온톨로지 정의
- 14 Layer 온톨로지 좌표 체계 (Strategic/Structural/Functional/Operational/Protocol)
- ID 기반 문서 관리 시스템 (298개 설계 문서, 53개+ 프로젝트 추적)

#### 스토리 2: 기술과 현장의 언어 불일치 → FMEA 자동화

> "일본 O-WELL 프로젝트에서 피쉬본 다이어그램을 개발했는데, **일본 관계자조차 이해하지 못했습니다**. 패턴 분석, 확률 네트워크도 마찬가지였습니다. 그래서 공장 관리자가 아는 **FMEA 형식**으로 자동 변환하는 시스템을 만들어 이해도를 **90% 향상**시켰습니다."

#### 스토리 3: LLM의 한계 → 특화 중간 DB (GFS)

> "LLM을 활용하다가 온톨로지를 잘 이해하지 못하고, 벡터만으로는 부족하다는 것을 깨달았습니다. '어차피 AI LLM은 앞뒤 주는 것만 잘하면 되니까' 특화 중간 DB(GFS)를 개발하여 LLM 비용을 **87% 절감**했습니다."
