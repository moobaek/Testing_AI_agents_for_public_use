# 권순룡 자기소개서 - 한화생명 AI 모델링 엔지니어

## 지원동기 (1000자 이내)

5년간 AI 모델 학습/평가와 AI Agent 시스템 개발을 통해 "데이터를 정보로, 정보를 지식으로" 전환하는 과정에서 임팩트 있는 경험을 쌓아왔습니다. 특히 Claude Sub-Agent 기반 Multi-Agent Workflow 구축, 32개 Python MCP 서버 개발, AI Agent Orchestration/Tool Calling 개발 경험이 한화생명 AI팀의 "가입설계, 보장분석 등 보험 현업 AI Agent 개발"과 "AI Agent Orchestration/Tool Calling 개발" 업무에 직접 기여할 수 있다고 생각합니다.

한화생명이 추구하는 "AI 기술을 통한 생산성 향상 및 제품 경험 증진"이라는 목표는 제가 FMEA 자동화 생성 시스템에서 구현한 8개 독립 Sub-Agent 협업 구조, Master Orchestrator 설계, Phase 0~5 자동화 워크플로우와 정확히 일치합니다. 마치 복잡한 공장 운영을 여러 전문가 팀이 협업하여 자동화하는 것처럼, 보험 업무도 가입설계, 보장분석, 리스크 평가 등 각 영역별 전문 Sub-Agent가 협업하면 훨씬 효율적으로 처리할 수 있을 것입니다.

또한 Neo4j 기반 지식 그래프 RAG 시스템 구축 경험은 보험 도메인의 복잡한 데이터를 구조화하고 활용하는 데 도움이 될 것입니다. 보험 상품, 고객 정보, 리스크 데이터 등이 서로 어떻게 연결되어 있는지 그래프로 표현하면, AI Agent가 더 정확한 판단을 내릴 수 있습니다. AMS 프로젝트에서 4M2E 관계를 정의하고 이상 탐지율 93.7%를 달성한 경험이 보험 리스크 분석에도 적용 가능할 것입니다.

한화생명 AI팀에서 보험 현업의 실제 문제를 해결하는 AI Agent를 개발하고, 최신 AI 트렌드를 적용하여 임직원과 고객 모두에게 가치 있는 서비스를 만들고 싶습니다.

## 경력기술(경력목표 포함) (1000자 이내)

5년간 한솔코에버 연구소에서 AI 모델 학습/평가, AI Agent 시스템 개발, 데이터 설계 등 다양한 프로젝트를 수행하며 전문성을 쌓아왔습니다. 특히 2024년부터는 Multi-Agent Workflow와 AI Agent Orchestration 분야에 집중하여, FMEA 자동화 생성 시스템에서 8개 독립 Sub-Agent 협업 구조를 설계하고 Master Orchestrator를 구현했습니다. Python 스크립트 없이 프롬프트 기반으로 Tool Calling 구조를 구현하여 개발 복잡성을 크게 감소시켰습니다.

AMS 프로젝트에서는 베이지안 네트워크 기반 이상 탐지 모델을 개발하고, 확률 최적화(경사하강법)를 통한 모델 학습을 수행하여 이상 탐지율 93.7%를 달성했습니다. 또한 Neo4j 그래프 DB 기반 지식 그래프 플랫폼을 구축하여 4M2E 관계를 정의하고, 온톨로지 기반 관계 분석을 통해 RAG 시스템을 구현했습니다. TAM_Hub 프로젝트에서는 32개 Python MCP 서버를 개발하여 AI Agent Tool 사용 경험을 쌓았고, 프롬프트 평가 엔진에서는 AI가 생성한 프롬프트를 다른 AI가 평가하는 이중 검증 시스템을 설계하여 환각(Hallucination)을 방지했습니다.

**경력목표**: 한화생명 AI팀에서 보험 현업 AI Agent 개발 전문가로 성장하여, 가입설계부터 보장분석까지 전 과정을 자동화하는 시스템을 구축하는 것이 목표입니다. 또한 최신 AI 트렌드를 지속적으로 학습하고 적용하여, 한화생명이 AI 기술을 통한 생산성 향상 및 제품 경험 증진을 달성하는 데 기여하고 싶습니다. 장기적으로는 보험 도메인 AI Agent 아키텍처 설계 전문가로 성장하여, 금융권 전반에 적용 가능한 AI Agent 플랫폼을 개발하는 것이 궁극적인 목표입니다.

## 입사 후 기여방안 (1000자 이내)

**1. 보험 현업 AI Agent 개발**: 제가 경험한 Multi-Agent Workflow를 보험 도메인에 적용하여, 가입설계, 보장분석 등 보험 현업 AI Agent를 개발하겠습니다. 8개 독립 Sub-Agent 협업 구조를 보험 업무 프로세스에 맞게 설계하고, Master Orchestrator를 통해 복잡한 보험 업무 프로세스를 자동화하겠습니다. Tool Calling 구조를 활용하여 보험 도메인 특화 Tool을 개발하고, 한화생명 내외에서 활용되는 다양한 AI 서비스를 구축하겠습니다.

**2. AI 모델 학습/평가**: 베이지안 네트워크 기반 모델 학습 경험을 보험 리스크 분석에 적용하겠습니다. 확률 최적화(경사하강법)를 통한 보험 모델 학습을 수행하고, 이중 검증 시스템을 통해 보험 모델 품질을 보장하겠습니다. AMS 프로젝트에서 달성한 93.7% 정확도 경험을 바탕으로, 보험 리스크 분석 모델의 정확도를 지속적으로 개선하겠습니다.

**3. RAG 시스템 구축**: Neo4j 기반 지식 그래프 RAG 경험을 활용하여 보험 도메인 지식을 구조화하겠습니다. 보험 상품, 고객 정보, 리스크 데이터를 Neo4j 그래프 DB로 구조화하고, 온톨로지 기반 관계 분석을 통한 보험 상품 추천 시스템을 구축하겠습니다. Retriever 학습/개선을 통해 보험 정보 검색 정확도를 향상시키겠습니다.

**4. 최신 AI 트렌드 적용 및 협업**: AI Agent 프로젝트 A-Z 개발 경험을 바탕으로 최신 AI 논문 및 프레임워크를 지속적으로 학습하고 적용하겠습니다. AI 프로젝트 PoC를 진행하여 새로운 기술의 적용 가능성을 검증하고, 5년간의 프로젝트 경험과 PM 경험을 바탕으로 팀 내 협업을 활성화하여 한화생명 AI팀 전체의 역량 향상에 기여하겠습니다.
