## 프로젝트 1: OntoFlow - 온톨로지 기반 지식그래프 플랫폼

**프로젝트명**: OntoFlow (Ontology-based Knowledge Flow Platform)
**고객사/Domain**: 한솔코에버 / 제조 데이터 통합
**수행 기간**: 2025.10 ~ 현재 (진행중)

**프로젝트 배경**:
5년간 쌓아온 온톨로지 기반 구조화 경험을 문서 자동화에 적용하였습니다. DPS와 AMS에서 Neo4j 지식그래프를 구축한 경험을 바탕으로, 문서에서 온톨로지를 자동 추출하는 시스템을 개발하게 되었습니다.

**업무 내용**:
- Obsidian 기반 문서에서 자동으로 온톨로지를 추출하여 지식그래프로 시각화하는 플랫폼 개발
- 엔티티 추출(파일, 태그, 링크), 관계 추출(wiki link, markdown link, tag relation) 자동화
- Neo4j 스타일 그래프 데이터 모델 설계 및 IndexedDB 기반 레이아웃 영속화
- LangChain/LangGraph 기반 AI 서비스 연동 준비

**담당 역할**: PM 및 핵심 아키텍처 설계
- 온톨로지 모델링: 문서-태그-링크 간 관계 스키마 설계
- 지식그래프 구축: vis-network 기반 인터랙티브 그래프 시각화
- 데이터 파이프라인: Python FastAPI 백엔드 + React 프론트엔드 연동
- API 기반 데이터 서비스: RESTful API 설계 및 구현

**보유/활용 Skill**: Python, FastAPI, Neo4j, React, TypeScript, vis-network, IndexedDB, Docker

## 프로젝트 2: DPS (Digital Production System) - 5층 아키텍처 지식기반 플랫폼

**프로젝트명**: DPS (데이터수집시스템)
**고객사/Domain**: 세아특수강, 포미아(포항소재산업진흥원) / 금속산업 제조
**수행 기간**: 2024.04 ~ 2024.12 (정식 납품 완료)

**프로젝트 배경**:
2020년 피쉬본(FBS) 구조에서 시작한 온톨로지 기반 접근법을 제조 플랫폼으로 확장하였습니다. CoCTK 데이터 전처리 엔진에서 쌓은 경험을 바탕으로, 제조 공정 전체를 아우르는 5층 아키텍처를 설계하게 되었습니다.

**업무 내용**:
- 금속산업 5대 공정(용해, 정련, 연주, 압연, 열처리)의 이질적인 데이터 소스를 통합하는 지식기반 데이터 플랫폼 개발
- 서비스/온톨로지/AI엔진/데이터수집/보안관리 5층 아키텍처 설계
- Neo4j 그래프 DB 기반 지식그래프 플랫폼 구축
- Docker 컨테이너 기반 마이크로서비스 아키텍처 구현

**담당 역할**: PM 및 핵심 아키텍처 설계
- 온톨로지 레이어 설계: 제조 공정 데이터의 의미적 관계 정의
- 지식그래프 저장: Neo4j 기반 공정-설비-품질 데이터 통합
- 데이터 파이프라인: Kafka 기반 실시간 데이터 수집 및 오케스트레이션
- API 기반 서비스: FastAPI RESTful API 개발

**보유/활용 Skill**: Python, FastAPI, Neo4j, PostgreSQL, Redis, Docker, Kubernetes, Kafka

**성과**:
- 세아특수강, 포미아 정식 납품 완료
- 2024년 학술 논문 발표
- 데이터 분석 시간 3일 → 10분 단축

## 프로젝트 3: AMS (Analysis Management System) - AI 기반 이상탐지 온톨로지 플랫폼

**프로젝트명**: AMS - AI 종합 플랫폼
**고객사/Domain**: 세아특수강, 포미아 / 제조 품질관리
**수행 기간**: 2024.07 ~ 2025.03 (GS 인증 1등급 취득)

**프로젝트 배경**:
DPS 5층 아키텍처에서 온톨로지 레이어를 구축한 경험을 극대화하여 AMS를 제작하였습니다. 단순히 데이터를 저장하는 것에서 나아가, 시계열 데이터를 의미 있는 관계로 변환하여 추론까지 수행하는 시스템을 목표로 하였습니다. 이를 통해 DPS와 AMS 모두 GS 인증 1등급을 취득하였습니다.

**업무 내용**:
- 베이지안 네트워크 기반 이상탐지 시스템 개발
- 시계열 분석 데이터를 정보 온톨로지로 변환하는 알고리즘 개발
- 피쉬본 다이어그램 자동생성 및 FMEA 자동화
- 확률 최적화(경사하강법)를 통한 이상상황 확률 네트워크 구축

**담당 역할**: PM 및 AI 플랫폼 개발 총괄
- 엔티티 추출: 공정 변수, 설비 상태, 품질 지표 자동 추출
- 관계 추출: 인과관계 네트워크 자동 구축 (베이지안 네트워크)
- 데이터 통합: 다중 소스 데이터 통합 및 정규화
- 추론 엔진: 확률적 추론을 통한 이상 원인 분석

**보유/활용 Skill**: Python, 베이지안 네트워크, Neo4j, FastAPI, Docker, 확률 최적화

**성과**:
- GS 인증 1등급 취득 (PDS 명칭)
- 이상탐지율 93.7% 달성
- 특허 등록 (피쉬본 다이어그램 자동화)
- 2024년, 2025년 학술 논문 발표

**담당 역할**: MCP 서버 설계 및 개발

- 오케스트레이션: 32개 MCP 서버 간 워크플로우 관리
- API 기반 서비스: Docker 기반 파서 서버 및 RESTful API
