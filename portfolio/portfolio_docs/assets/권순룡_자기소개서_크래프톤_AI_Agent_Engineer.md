# 권순룡 자기소개서 - 크래프톤 AI Agent Engineer

---

## 지원동기

5년간 AI Agent 시스템 개발을 통해 "데이터를 정보로, 정보를 지식으로" 전환하는 과정에서 생산성 향상을 실현해왔습니다. 특히 Claude Sub-Agent 기반 Multi-Agent Workflow 구축, 32개 Python MCP 서버 개발, FastAPI/LangGraph 기반 평가 프레임워크 개발 경험이 크래프톤 AI Agent Dev Team의 "AI가 단순한 도구를 넘어 팀의 동료로서 새로운 방식으로 협업"하고 "사람들이 일하는 방식을 완전히 바꾸고, 개개인의 생산성을 극대화하는" 목표와 정확히 일치합니다.

크래프톤이 추구하는 "딥러닝 기술을 활용해 업무의 생산성과 편의성을 향상시키고 새로운 크리에이티브를 만들 수 있는 플랫폼 서비스 개발"은 제가 FMEA 자동화 생성 시스템에서 구현한 8개 독립 Sub-Agent 협업 구조, Master Orchestrator 설계, Phase 0~5 자동화 워크플로우와 동일합니다. 마치 게임 개발에서 여러 전문가가 협업하여 크리에이티브를 만드는 것처럼, AI Agent도 각자의 전문 영역을 가진 Sub-Agent들이 협업하면 더 효율적이고 창의적인 결과를 만들 수 있을 것입니다. Evaluation Framework에서 FastAPI와 LangGraph를 활용하여 워크플로우 오케스트레이션을 구현한 경험은 크래프톤의 핵심 요구사항인 LangGraph와 우대사항인 FastAPI에 직접 부합합니다.

크래프톤 AI Agent Dev Team에서 Agentic AI를 개발하고, 최신 AI 트렌드를 적용하여 게임 개발 생산성을 향상시키고 새로운 크리에이티브 플랫폼을 만드는 데 기여하고 싶습니다.

## 경력기술(경력목표 포함)

5년간 한솔코에버 연구소에서 AI Agent 시스템 개발, Prompt Engineering, MCP Server 개발 등 다양한 프로젝트를 수행하며 전문성을 쌓아왔습니다. 특히 2024년부터는 Multi-Agent Workflow와 AI Agent Orchestration 분야에 집중하여, FMEA 자동화 생성 시스템에서 8개 독립 Sub-Agent 협업 구조를 설계하고 Master Orchestrator를 구현했습니다. Python 스크립트 없이 프롬프트 기반으로 Tool Calling 구조를 구현하여 개발 복잡성을 크게 감소시켰습니다.

TAM_Hub 프로젝트에서는 32개 Python MCP 서버를 개발하여 MCP Server 개발 경험을 쌓았고, 프롬프트 평가 엔진에서는 AI가 생성한 프롬프트를 다른 AI가 평가하는 이중 검증 시스템을 설계하여 환각(Hallucination)을 방지했습니다. 또한 25개+ 프롬프트 체인을 개발하여 Few-shot, Chain-of-Thought 기법을 적용한 프롬프트 최적화 경험을 쌓았습니다. Evaluation Framework에서는 FastAPI와 LangGraph를 활용하여 워크플로우 오케스트레이션을 구현하고, 49개 Python 모듈과 298개 문서 전체를 전수 검사하는 거대 평가 엔진을 구축했습니다.

**경력목표**: 크래프톤 AI Agent Dev Team에서 Agentic AI 개발 전문가로 성장하여, 게임 개발 생산성을 향상시키고 새로운 크리에이티브를 만들 수 있는 플랫폼 서비스를 개발하는 것이 목표입니다. 특히 Multi-Agent Workflow와 Agent Orchestration 분야에서 전문성을 더욱 확대하여, AI가 단순한 도구를 넘어 팀의 동료로서 협업할 수 있는 시스템을 구축하고 싶습니다. 장기적으로는 게임 도메인 AI Agent 아키텍처 설계 전문가로 성장하여, 크래프톤만의 독창적인 AI Agent 플랫폼을 개발하는 것이 궁극적인 목표입니다.

## 입사 후 기여방안

**1. 생산성 향상 플랫폼 개발**: 제가 경험한 Multi-Agent Workflow 시스템을 게임 개발 프로세스에 적용하여 생산성을 향상시키겠습니다. 게임 기획, 아트, 프로그래밍, QA 등 각 영역별 전문 Sub-Agent를 설계하고, Master Orchestrator를 통해 전체 워크플로우를 자동화하겠습니다. Python 스크립트 없이 프롬프트 기반으로 구현한 경험을 활용하여 개발 복잡성을 감소시키고, FastAPI와 LangGraph를 활용한 워크플로우 오케스트레이션을 구축하겠습니다.

**2. Prompt Engineering 및 프롬프트 최적화**: 다양한 목적의 프롬프트를 제작하고 테스트한 경험, 프롬프트 최적화(Few-shot, Chain-of-Thought) 경험을 바탕으로 게임 개발에 필요한 프롬프트를 개발하고 최적화하겠습니다. 프롬프트 평가 엔진을 활용하여 프롬프트 품질을 자동으로 검증하고, 스스로 개발한 AI를 통해 업무 효율이 향상됨을 직접 실현하겠습니다.

**3. MCP Server 개발 및 Agent Tool 사용**: 32개 Python MCP 서버 개발 경험을 바탕으로 크래프톤 내부 시스템과 통합 가능한 MCP 서버를 개발하겠습니다. Neo4j 기반 지식 그래프 RAG 시스템을 활용하여 게임 관련 지식을 구조화하고, AI Agent Tool을 개발하여 다양한 업무에 활용할 수 있도록 하겠습니다.

**4. 최신 AI 트렌드 적용 및 협업**: AI Agent 프로젝트 A-Z 개발 경험을 바탕으로 최신 AI 논문 및 프레임워크를 지속적으로 학습하고 적용하겠습니다. 문제를 빠르게 정의하고 풀 수 있는 사고 능력, 변화하는 환경에 빠르게 맞출 수 있는 능력을 바탕으로 새로운 기술 트렌드를 파악하고 공유하며, 업무 생산성에 기여할 수 있는 방법을 지속적으로 고민하겠습니다. 또한 5년간의 프로젝트 경험과 PM 경험을 바탕으로 팀 내 협업을 활성화하여 크래프톤 AI Agent Dev Team 전체의 역량 향상에 기여하겠습니다.
