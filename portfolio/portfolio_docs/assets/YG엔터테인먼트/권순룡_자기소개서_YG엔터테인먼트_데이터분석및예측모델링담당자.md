## 경력기술(경력목표 포함)

5년간 한솔코에버 연구소에서 AI 기반 제조 솔루션 개발 및 프로젝트 관리, 데이터 분석 및 예측 모델링, 데이터 파이프라인 설계를 담당했습니다. AMS 프로젝트(2024.7-2025.3)에서는 AI 종합 플랫폼 개발을 총괄하여 49개 Python 모듈로 구성된 ML 파이프라인을 구축하고, 확률 최적화(경사하강법) 기반 이상탐지 모델을 개발하여 이상탐지율 93.7%를 달성했습니다. 또한 8단계 시계열 데이터 파이프라인을 설계하여 데이터 전처리부터 모델 학습, 예측, 결과 시각화까지 전 과정을 자동화했으며, 피쉬본 다이어그램 자동생성 기능을 개발하여 시각화 대시보드를 구현했습니다. 해당 성과로 GS 인증 1등급을 취득하고 세아특수강과 포미아에 정식 납품했으며, 학술 논문 2건을 발표했습니다.

DPS 프로젝트(2021-2024)에서는 Docker 기반 마이크로서비스 아키텍처와 Kubernetes 오케스트레이션으로 서버-엣지 하이브리드 인프라를 구축하여 세아특수강과 포미아에 정식 납품했습니다. CoCTK 프로젝트(2022.3-2024)에서는 엔진 총괄 설계 및 화면설계 개발을 총괄하여 데이터 전처리, 상관관계 분석, 비용 최적화를 통한 인사이트 도출 시스템을 구축했으며, GS 인증 1등급을 취득했습니다. FMEA 자동화 프로젝트(2025-)에서는 LLM 기반 Multi-Agent 시스템을 개발하여 8개 독립 Sub-Agent가 협업하는 구조를 구축했으며, Claude Code Task tool 기반 Master Orchestrator를 설계했습니다. Evaluation Framework 프로젝트(2025.10-)에서는 FastAPI와 LangGraph로 49개 Python 모듈과 298개 문서를 전수 검사하는 평가 엔진을 구축했습니다. Data Hub 프로젝트(2025.6-12)에서는 PostgreSQL RDB를 설계하여 메타데이터 관리 시스템을 구축하고 다양한 외부 데이터베이스와의 연결을 관리했습니다.

**단기 목표**: YG 데이터사이언스팀에서 데이터 분석 및 예측 모델링을 통해 인사이트를 제공하고, AI/ML 모델 개발을 통해 비즈니스 가치를 창출하는 것입니다. 특히 Gen AI 및 LLM 기반의 실무 적용 경험을 바탕으로, 팬덤 플랫폼 데이터 분석 및 예측 모델 개발에 기여하고 싶습니다.

**장기 목표**: 데이터사이언스 전문가로서 엔터테인먼트 산업의 데이터 기반 의사결정을 선도하고, 예측 모델 및 업무 자동화 파이프라인을 통해 실질적인 업무 효율화를 지원하는 것입니다. 또한 학술 연구를 통해 엔터테인먼트 산업의 데이터사이언스 분야에 기여하고 싶습니다.

## 입사 후 기여방안

YG엔터테인먼트 데이터사이언스팀에서 데이터 분석 및 예측 모델링 담당자로서 다음과 같이 기여하고 싶습니다.

**1. 데이터 분석을 통한 인사이트 도출 및 시각화 대시보드 구현**

AMS 프로젝트에서 피쉬본 다이어그램 자동생성 기능을 개발하고, CoCTK 프로젝트에서 화면설계 개발을 총괄한 경험을 바탕으로, 팬덤 플랫폼 데이터와 사내 비즈니스 데이터를 분석하여 인사이트를 도출하고, 이를 시각화 대시보드로 구현하겠습니다. 특히 시계열 데이터 분석, 상관관계 분석, 확률 네트워크 분석 등 다양한 데이터 분석 기법을 활용하여 엔터테인먼트 산업에 특화된 인사이트를 제공하겠습니다.

**2. AI/ML 모델 개발**

49개 Python 모듈로 구성된 ML 파이프라인을 구축하고, 이상탐지율 93.7%를 달성한 경험을 바탕으로, 팬덤 플랫폼 사용자 데이터 분석을 위한 예측 모델을 개발하겠습니다. 특히 품질 예측 AI 엔진 개발 경험을 활용하여, 사용자 행동 예측, 콘텐츠 추천, 수익 예측 등의 모델을 개발하겠습니다.

**4. Gen AI 및 LLM 기반 실무 적용**
