## 프로젝트 1: FMEA 자동화 생성 시스템 (Claude Sub-Agent)

**프로젝트명**: FMEA 자동화 생성 시스템 (Claude Sub-Agent)  
**시작일**: 2024-01-24  
**종료일**: 2025-12-31  
**사내프로젝트**: ✅ 예  
**저장소속회사명**: 한솔코에버  
**주사용기술**: Claude API, Python, 프롬프트 엔지니어링, Multi-Agent Workflow, Tool Calling, MCP 프로토콜

**프로젝트 소개 및 본인 역할**:

본 프로젝트는 AIAG & VDA FMEA 표준을 기반으로 한 범용 리스크 분석 시스템을 Claude Sub-Agent 기반 Multi-Agent Workflow로 구현한 프로젝트입니다. 복잡한 FMEA 프로세스를 역으로 분석하여 8개 독립 Sub-Agent로 분해하고, 각 Sub-Agent가 전문 영역(R&D Team 3개, Manufacturing Team 3개, QA Team 2개)을 담당하는 구조를 설계했습니다.

본인은 Master Orchestrator 설계 및 개발을 담당했습니다. Claude Code Task tool을 활용하여 Python 스크립트 없이 프롬프트 기반 완전 자동화를 구현했으며, Phase 0~5 자동화 워크플로우(컨텍스트 수집 → 범위 정의 → 심층 분석 → 리스크 평가 → 최적화 & 문서 생성 → 지속 개선)를 설계했습니다. Tool Calling 구조를 구현하여 개발 복잡성을 크게 감소시켰고, 코딩 에이전트의 역설계 시스템 구조를 적용하여 전체 공장/회사/사무 자동화의 백정보 핵심을 구축했습니다.

주요 성과로는 8개 Sub-Agent 협업 구조 설계, 프롬프트 기반 완전 자동화 구현, Phase 0~5 워크플로우 자동화 완료를 달성했습니다. 이 프로젝트는 카카오 Agent Builder의 Multi-Agent Workflow와 Tool Calling 구조와 직접적으로 연관되어 있으며, A2A 프로토콜을 통한 에이전트 네트워크 구축 경험을 제공합니다. 해당 성과로 논문 발표를 진행했습니다.

주요 성과로는 25개+ 프롬프트 품질 보장, 이중 검증 시스템 구축, 환각 방지 시스템 구현을 달성했습니다. 이 프로젝트는 카카오 Agent Builder의 AI Prompt Engineering 요구사항과 직접적으로 연관되어 있으며, 프롬프트 품질 관리 경험을 제공합니다.

본인은 평가 엔진 설계 및 개발을 담당했습니다. FastAPI 기반 평가 엔진을 개발하고, LangGraph를 활용하여 워크플로우 오케스트레이션을 구현했습니다. 6가지 관점 평가 프로세스를 설계했으며, 49개 Python 모듈과 298개 문서 전체를 전수 검사하는 시스템을 구축했습니다. Docker 컨테이너 기반 배포 시스템을 구축하고, React 기반 대시보드를 개발했습니다.

주요 성과로는 전체 아키텍처 건전성 보장, 6가지 관점 평가 시스템 구축, 자동화된 평가 프로세스 구현을 달성했습니다. 이 프로젝트는 카카오 Agent Builder의 Java/Kotlin 및 Spring 기반 웹 서비스 개발 경력 요구사항과 연관되어 있으며, FastAPI 기반 백엔드 개발 경험을 제공합니다.
