## 🎯 사용 방법

1. 해당 프로젝트 단계의 폴더로 이동
2. `README.md`에서 필요한 문서 체크리스트 확인
3. 하위 폴더의 템플릿을 복사하여 프로젝트에 맞게 수정
4. 프로젝트 종료 전 `4_verification_checklist`로 최종 검증
