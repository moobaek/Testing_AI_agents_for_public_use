# 4. Verification Checklist (검증 체크리스트)

프로젝트 종료 전 최종 완성도 검증을 위한 Phase 1-10 체크리스트입니다.

---

## ✅ 검증 개요

| 항목 | 설명 |
|------|------|
| **목적** | 프로젝트 종료 전 모든 산출물 및 프로세스 완성도 검증 |
| **기준** | 80점 이상 시 종료 GO, 70-80점 추가 보완 필요 |
| **사용 시점** | 프로젝트 종료 2주 전 시작 |

---

## 🎯 활용 가이드

### 1. 검증 시작
- 각 Phase 파일을 열어 항목별 체크
- 완료 항목은 `☐` → `☑` 변경
- 담당자 및 비고 기록

### 2. 점수 산정
- 각 Phase 완료 항목 수 집계
- 가중치 적용하여 점수 계산
- 총점 환산 (88점 → 100점)

### 3. 결과 조치
- 80점 이상: 종료 보고 진행
- 70-80점: 미흡 항목 보완 후 재검증
- 70점 미만: 경영진 검토 회의 진행

---

## ⚠️ 주의사항

> [!CAUTION]
> - Phase 1-5는 **필수 항목** (가중치 높음)
> - 고객 서명이 필요한 항목은 **원본 보관** 필수
> - 검증 결과는 **종료 보고서에 첨부**
