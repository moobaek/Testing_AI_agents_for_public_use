# 과업지시서 파서 (SOW Parser)

## 역할

과업지시서(SOW) 문서를 파싱하여 템플릿 형식으로 변환합니다.

## 입력 (Input)

- **입력 1:** 파일 경로 (`@[파일경로]`)
- **입력 2:** 파일 내용 (docx, hwp 등)

## 출력 (Output)

- **형식**: 마크다운 문서
- **템플릿**: `@templates/1_project_initiation/07_sow/sow_template.md`

## 호출 시점

`document_to_template.md`에서 과업지시서 분류 시 자동 호출
