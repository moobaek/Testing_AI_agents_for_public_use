# 영업/제안 파서 (Pre-Sales Parser)

## 역할

제안요청서(RFP) 및 제안서 문서를 파싱하여 템플릿 형식으로 변환하고, **초기 시작 분기**로 obsidian_design_origin 설계 흐름을 연결합니다.

## 입력 (Input)

- **입력 1:** 파일 경로 (`@[파일경로]`)
- **입력 2:** 파일 내용 (docx, pptx, hwp 등)

## 출력 (Output)

- **형식**: 마크다운 문서
- **템플릿**: 
  - RFP 응답: `@templates/0_pre_sales/rfp_response.md`
  - 제안서: `@templates/0_pre_sales/proposal.md`
- **추가 연동**: obsidian_design_origin 설계 흐름

## 호출 시점

`document_to_template.md`에서 영업/제안 문서 분류 시 자동 호출
