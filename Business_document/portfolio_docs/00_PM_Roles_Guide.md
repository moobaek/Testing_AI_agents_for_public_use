# AI 기반 프로젝트 관리 방법론 (AI-Augmented PM Methodology)

**문서 ID**: `guide.pm.roles`

> [!IMPORTANT] 패러다임 전환 (Paradigm Shift)
> **"인간은 결정을 내리고, AI는 관리(Track)합니다."**
> 기존의 PM은 일정표를 업데이트하느라 하루를 보냈습니다. 당사의 **AI PM 에이전트**는 로그를 실시간으로 분석하여 지연 리스크를 0.1초 만에 감지하고 경고합니다.
> 이것이 바로 **관리 비용을 90% 절감하는** 미래의 프로젝트 관리 방식입니다.

---

## 1. 이원화 관리 체계 (Dual-Track Management)

당사의 솔루션은 프로젝트의 성공을 위해 **'비즈니스 관리'**와 **'기술 구현'**을 분리하되, 이를 **AI 에이전트**가 실시간으로 조율하는 독자적인 체계를 갖추고 있습니다.

### 🤖 총괄 PM 에이전트 (Program Manager Agent)
**"계약부터 납품까지, 빈틈없는 리스크 관리"**

*   **역할**: 프로젝트의 '숲'을 봅니다. 계약 조건, 자금 흐름, 고객 커뮤니케이션을 전담합니다.
*   **AI 능력 (AI Capabilities)**:
    *   **계약서 독소 조항 자동 스캔**: 수백 페이지의 제안요청서(RFP)를 분석하여 이행 불가능한 독소 조항을 3분 내에 찾아냅니다.
    *   **일정 지연 예측**: 간트 차트(Gantt Chart)와 실제 업무 로그를 비교하여, "현재 속도라면 2주 뒤 마일스톤이 지연될 확률이 85%입니다"라고 경고합니다.
    *   **회의록 자동 분석**: 고객과의 미팅 녹취록에서 '추가 요구사항(Scope Creep)'을 감지하고 즉시 변경 요청서 초안을 작성합니다.

### 🛠️ 개발 PM 에이전트 (Technical PM Agent)
**"코드 품질과 아키텍처의 수호자"**

*   **역할**: 기술적 난제를 해결하고 개발팀의 퍼포먼스를 최적화합니다.
*   **AI 능력 (AI Capabilities)**:
    *   **아키텍처 정합성 검사**: 개발자가 작성한 코드가 전체 아키텍처 설계와 충돌하지 않는지 실시간으로 감시합니다.
    *   **기술 부채(Technical Debt) 시각화**: "이 모듈은 결합도가 너무 높습니다"라는 리포트를 통해 리팩토링 우선순위를 제안합니다.
    *   **문서 자동 동기화**: 코드가 수정되면, 관련된 API 명세서와 다이어그램을 AI가 자동으로 업데이트합니다.

## 2. 프로젝트 리스크 관리 (AI Risk Management)

AI는 24시간 잠들지 않고 프로젝트의 건강 상태를 모니터링합니다.

| 리스크 유형 | 기존 관리 방식 (Human) | **AI 에이전트 대응 (Our Solution)** | 기대 효과 |
| :--- | :--- | :--- | :--- |
| **일정 지연** | 주간 회의 때 발견 (이미 늦음) | **실시간 로그 분석**으로 지연 징후 즉시 포착 | 골든타임 확보 |
| **요구사항 변경** | 이메일 구석에 묻혀 누락됨 | 모든 커뮤니케이션 채널을 **전수 모니터링**하여 변경점 추적 | 분쟁 예방 |
| **품질 저하** | 배포 전날 밤샘 테스트 | 코드가 커밋될 때마다 **AI QA 에이전트**가 1,000개 시나리오 테스트 | 무결점 배포 |

## 3. 핵심 성과 지표 (Key Performance Indicators)

당사의 AI 관리 시스템을 도입한 프로젝트들은 압도적인 성공률을 기록했습니다.

### ✅ 정량적 성과
*   **납품 성공률 100%**: 세아특수강, 포미아 등 대기업 및 공공기관 프로젝트 전수 성공 납품.
*   **문서 정확도 99%**: 사람이 작성할 때 발생하는 오타나 버전 불일치를 AI가 완벽하게 보정.
*   **커뮤니케이션 비용 60% 절감**: 불필요한 현황 파악 회의가 사라지고, 의사결정 회의만 남음.

### 🏆 주요 성공 사례
*   **세아특수강 DPS**: 복잡한 5단계 공정 데이터 파이프라인 구축을 단 1회의 지연 없이 완수.
*   **AMS (이상탐지시스템)**: 5년 장기 R&D 과제를 성공적으로 관리하여 '우수' 등급 종료 및 특허 확보.
