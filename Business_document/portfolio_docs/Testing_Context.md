# Enterprise Pilot Reports: 현장 실증 리포트

**문서 ID**: `page.portfolio.testing`

> [!NOTE] 실증의 목적 (Purpose of Verification)
> 실험실 환경(Lab)과 실제 산업 현장(Field)은 다릅니다.
> 본 리포트는 당사의 솔루션이 **가장 열악하고 복잡한 실제 제조 현장**에서 어떻게 작동하고 가치를 증명했는지에 대한 **가감 없는 실증 기록**입니다.

---

## 🏗️ Pilot Case 1: 세아특수강 (SeAH Special Steel)

**프로젝트**: DPS (데이터 통합 처리 시스템) 구축
**기간**: 2025년 상반기

### 🚩 도전 과제 (Challenge)
*   **복잡성**: 5단계로 분리된 공정에서 발생하는 이기종 데이터(PLC, MES, 작업자 수기 기록)가 파편화되어 있음.
*   **신뢰성**: 기존 수기 데이터의 오기입으로 인해 생산 이력 추적이 불가능함.

### 💡 AI 도입 효과 (Resolution)
당사의 **DPS 플랫폼**과 **데이터 검증 에이전트**를 투입하여 데이터 파이프라인을 완전 자동화했습니다.

| 비교 항목 | 도입 전 (AS-IS) | **도입 후 (TO-BE)** | 개선율 |
| :--- | :--- | :--- | :--- |
| **데이터 수집** | 작업자가 수기 입력 (일 30분 소요) | **밀리초(ms) 단위 실시간 자동 수집** | **∞ (완전 자동화)** |
| **데이터 정합성** | 오기입률 15% | **오기입률 0% (AI 자동 보정)** | **품질 100% 확보** |
| **장애 대응** | 장애 발생 후 4시간 뒤 인지 | **0.1초 내 이상 징후 감지 및 경보** | **대응 속도 99% 단축** |

### 🛠️ 검증 결과
*   **무중단 운영**: 구축 후 3개월간 시스템 다운타임 0시간 기록.
*   **현장 검수 완료**: 현장 작업자와 품질 관리자의 교차 검증 통과.

## 🔬 Pilot Case 2: 포미아 (POMIA, 포항소재산업진흥원)

**프로젝트**: AMS (이상 관리 시스템) 통합 구축
**기간**: 2025년 상반기

### 🚩 도전 과제 (Challenge)
*   **전문성 부족**: 설비 이상 발생 시, 20년 경력의 베테랑만이 원인을 파악할 수 있어 기술 의존도가 극도로 높음.
*   **분석 시간**: 고장 원인 분석부터 보고서(FMEA) 작성까지 평균 3일 소요.

### 💡 AI 도입 효과 (Resolution)
**피쉬본 분석 AI**와 **FMEA 생성 에이전트**를 도입하여 전문가의 지식을 시스템화했습니다.

| 비교 항목 | 도입 전 (AS-IS) | **도입 후 (TO-BE)** | 개선율 |
| :--- | :--- | :--- | :--- |
| **원인 분석** | 전문가 직관 의존 (평균 4시간) | **AI가 1초 만에 확률적 원인 제시** | **3,600배 가속** |
| **보고서 작성** | 엑셀 수작업 (평균 2일) | **AI가 즉시 초안 생성 (1분)** | **업무 효율 99% 향상** |
| **지식 자산화** | 전문가 퇴사 시 노하우 소실 | **시스템에 영구적인 지식 DB 구축** | **자산 영구 보존** |

### 🛠️ 검증 결과
*   **분석 정확도**: 전문가 판단 결과와 AI 예측 결과의 일치율 **93.7%** 달성.
*   **GS 인증 획득**: 해당 실증 결과를 바탕으로 소프트웨어 품질 인증 1등급 획득.

## ⚡ Pilot Case 3: 에너지 최적화 실증

**프로젝트**: 클린룸 공조 설비 에너지 효율화
**기간**: 2023 - 2024

### 🚩 도전 과제 (Challenge)
*   **과잉 냉방**: 안전율을 고려해 항상 100% 가동하여 불필요한 전력 낭비 심각.
*   **센서 부족**: 모든 지점에 온도 센서를 설치하기에는 비용 부담이 큼.

### 💡 AI 도입 효과 (Resolution)
**가상 센서(Virtual Sensor)**와 **예측 제어 AI**를 도입했습니다.

*   **Virtual Sensor**: 센서가 없는 지점의 온도를 AI가 98% 정확도로 추정.
*   **AI 제어**: 실시간 부하 예측을 통해 팬(Fan) 속도를 자동으로 조절.
*   **결과**: 연간 전력 비용 **20% 절감** 달성 (ROI 6개월).
